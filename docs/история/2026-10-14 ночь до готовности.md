## Опыт

- Параметр эффекта — один токен: блок `{ value = … }` аргументом не компилируется — сумму передавать переменной.
- Движок собирает каждую пару параметров, которую называет вызов (`$H$_$K$`), и ветки, которые никогда не исполняются, —
  читателю нужна пустая заглушка, иначе «Unknown effect» при загрузке.
- Заявка с шагом цены вне стакана не ставится молча — у политики продажи (свои облигации) шаг надо прижимать к верху.
- Архив входа покупок (облигации ИИ E&F) убрал единственный источник долей — торговля облигациями встала, пока не
  заработал новый вход (свои облигации банков).
- Защита авто-режима иногда не отвечает на команды оболочки; работа файловыми инструментами между попытками не
  останавливает ночь.
