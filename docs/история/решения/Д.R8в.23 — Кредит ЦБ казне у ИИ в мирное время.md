# Д.R8в.23 — Кредит ЦБ казне у ИИ в мирное время

## Решили

Кредит ЦБ казне у ИИ в мирное время (E&F) — только до 25 % предела золотого резерва казны и в пределах разрешённого долга, не весь разрешённый долг разом (движок сжигает деньги казны сверх предела); временная мера, механика долга через ЦБ — R5
