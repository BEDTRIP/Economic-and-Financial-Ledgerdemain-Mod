# Д.R8в.24 — Регулятор стройки покупает все четыре стройматериала

## Решили

Регулятор стройки покупает все четыре стройматериала: 10 единиц любого — очко; делёж закупки — по предложению рынка × (самая низкая местная цена / цена товара)², шаг к нему — половина за неделю; очки за траты штата — модель цены PSC по базовой цене смеси (очки по текущей цене обвалили выпуск секторов, прогон r1011_142626); выбор метода по сектору/технологии — в архив
