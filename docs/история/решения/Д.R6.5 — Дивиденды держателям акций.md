# Д.R6.5 — Дивиденды держателям акций

## Решили

Дивиденды держателям акций (пользователь 14.10; решает В.R6.4, вариант 1): пока без выплат — игра сама платит прибыль зданий их владельцам, выплата держателям посчитала бы её дважды; цена акции — от годового дохода компании по её счёту (Д.R6.2) / (ставка правительства + 4 п. п.) (Д2.10); держатель зарабатывает на цене и продаже
