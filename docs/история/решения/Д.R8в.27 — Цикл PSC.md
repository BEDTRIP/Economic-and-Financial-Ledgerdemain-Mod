# Д.R8в.27 — Цикл PSC

## Решили

Цикл PSC (аудит): доли закупки регулятора — до весов штатов; вес штата и его доля трат — по стоимости выпуска (выпуск × базовая цена смеси) × укомплектованность регулятора (не меньше 0,05: регулятор платит государственную зарплату и пустует там, где работа платит больше), не по выпуску / цене; траты штата не ниже 0; пропускная регулятора — на укомплектованный уровень (уровень × занятость, не меньше 0,1); регулятор не сносится, только растёт до уровня сектора
