# Д.R8б.27 — Эталон без кандидатов

## Решили

Эталон без кандидатов: если ни одна страна не прошла отбор, эталон остаётся у прежнего (и фиатного), пока страна существует; нет прежнего — крупнейшая по ёмкости в золоте великая держава с ЦБ при любом стандарте
