# Д.П.1 — Явление из жизни — через механику движка или мода, которая его уже

## Решили

Явление из жизни — через механику движка или мода, которая его уже имитирует (коррупция — нехватка бюрократии, преступность и недоверие — радикалы, маргинальность — статус терпимости, металл обменного стандарта — законы); новая переменная, кнопка или модификатор — только если такой механики нет, с объяснением, что искал
