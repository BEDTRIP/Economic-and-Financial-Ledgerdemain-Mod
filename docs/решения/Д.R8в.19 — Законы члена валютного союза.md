# Д.R8в.19 — Законы члена валютного союза

## Решили

Законы члена валютного союза: денежная система (стандарт) и денежная политика — как у главы: при вступлении принимаются сразу, при смене закона у главы — у всех членов тут же; сам член их не меняет (подсказка закона — «член валютного союза»); закон «Центральный банк» у члена — свой, можно без ЦБ (валюту союза по общему паритету выпускают свободные банки или казна, металл страны — в общем покрытии); глава — только страна с ЦБ: самый престижный член с ЦБ, лидер блока без ЦБ союз блока не возглавляет (статья недоступна, пока нет ЦБ)
