# Д.R4а.13 — Кубышка — металлический счёт казны

## Решили

Кубышка — металлический счёт казны (В.R4а.5, пользователь 12.10; заменяет Д.R8.9): казна держит деньги своей страны, облигации (свои и чужие) и металл — свой счёт, отдельный от резерва денежной власти, ничего не покрывает; купить и продать — на бирже по рынку; сдать денежной власти по паритету с комиссией (валюта — в казну, выпуск под металл); выкупить у власти за валюту — при ЦБ только сверх нормы покрытия; без ЦБ при фиате, обменном, внешневалютном власть — сама казна, перекладка без комиссии; при металлическом без ЦБ — продажа металла банкам по паритету; ИИ — продаёт в казну при угрозе дефолта; окно рядом с облигациями — R10, в R4а — блок панели экономики
