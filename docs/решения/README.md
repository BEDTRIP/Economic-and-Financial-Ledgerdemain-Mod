# Решения форка

Файл на решение — `Д.<этап>.<n> — <тема>.md` ([[Решение|методика]]); заменённые — `история/решения/`. Решения до 29.10 разложены из реестра одной таблицей скриптом: «Решили» — текст строки реестра, «Статус в реестре» — как было; вопрос в заголовке, «Последствия» и «Отвергнуто» — при следующей правке решения.

```base
filters:
  and:
    - file.inFolder(this.file.folder)
    - note.type == "decision"
views:
  - type: table
    name: Решения
    order:
      - file.name
      - status
      - date
    sort:
      - property: file.name
        direction: ASC
```
