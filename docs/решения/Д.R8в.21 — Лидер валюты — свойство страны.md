# Д.R8в.21 — Лидер валюты — свойство страны

## Решили

Лидер валюты — свойство страны: ЦБ на стандарте, не привязан банком к чужой валюте, не последователь валютного союза; средняя валюта E&F (медиана) — среднее ценности в золоте по всем лидерам, с национальными валютами; курс валюты E&F — её лидер с наибольшей ёмкостью; списки и модификаторы лидера E&F — в архив
