# Д.R8б.16 — Капитал фонда

## Решили

Капитал фонда: на старте — вклад банков страны биржи (доля их капитала); паи — товар, который производит здание фонда, покупают население (потребность в финпродуктах) и банки (вход зданий «Банк»); покупка — взнос в капитал, покупатель получает паи (требование на фонд); прибыль остаётся в фонде
