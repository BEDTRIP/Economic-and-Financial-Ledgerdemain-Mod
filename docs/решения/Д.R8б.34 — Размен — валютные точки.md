# Д.R8б.34 — Размен — валютные точки

## Решили

Размен — валютные точки: ЦБ металлического или обменного стандарта с разменом выкупает свою валюту по паритету − комиссия (платит металлом или валютой якоря) и продаёт по паритету + комиссия — курс ходит между точками без других ручек. Фиат точек не имеет: база — покупательная способность ([[Д.R8б.29 — Фиат в золоте|Д.R8б.29]]), спрос — биржа (торговля через клиринг, резервы держателей), защита курса — ЦБ по своей воле резервами
