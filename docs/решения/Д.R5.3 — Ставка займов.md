# Д.R5.3 — Ставка займов

## Решили

Ставка займов (пользователь 12.10; решает В.R5.5): ключевая ставка + премия; премия = риск рейтинга + загрузка (долг игры / реальный предел: до 50 % — 0, дальше растёт, сверх предела — круто) + слагаемые игры, кроме базы 20 %, × 0,25 (технология −0,5 п. п., поправки конституции +0,25…+1,25 п. п.); множители игры — поправка премии ×0,5…×2, как сейчас; не ниже ключевой
