# Д.R8а.5 — Покрытие — одно число

## Решили

Покрытие — одно число: резервы по рынку в металле стандарта. Металлический — **только свой металл**; обменный, внешневалютный, фиат — плюс валюты обменоспособных эмитентов по курсу прошлого месяца
