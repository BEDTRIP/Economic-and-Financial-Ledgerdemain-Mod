# Д.R6.3 — Акции поштучно

## Решили

Акции поштучно (пользователь 13.10; решает В.R6.3, вариант 2 с уточнением): каждая крупная компания — свои акции (после пробы цены); мелкие держатели и мелкие выпуски — собиратель, как «частные банкиры» у банков и паи у фондов; банки — компании, их акции — акции компаний; паи фондов уже акции фонда. Один тип акций (пользователь 14.10): без деления на обыкновенные / привилегированные и по отраслям; разбивка по типам зданий компании — только в аналитике (витрина, отчёты)
