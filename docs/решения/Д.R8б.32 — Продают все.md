# Д.R8б.32 — Продают все

## Решили

Продают все: каждый держатель выставляет каждый актив по своей цене — справедливая × (1 + надбавка держателя, Д.R8б.20); мелкая позиция — со скидкой, продаётся первой (порядок Д.R8б.22); покупают только по заявкам; биржа — не поиск продавцов, а расчистка хранилищ (ответ на В-R8б.4)
