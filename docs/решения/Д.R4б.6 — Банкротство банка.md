# Д.R4б.6 — Банкротство банка

## Решили

Банкротство банка (В.R4б.3, пользователь 12.10): раз в месяц субъект-банк с капиталом < 0 без кредита ЦБ закрывается — его вклады и кредиты переходят остальным банкам страны пропорционально, вкладчики теряют долю дыры; без ЦБ это паника свободных банков. Санация (кредит ЦБ последней инстанции) — потом, отдельным решением
