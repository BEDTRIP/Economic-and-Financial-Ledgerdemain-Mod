# Д.R4б.21 — Разрыв рынка движка

## Решили

Разрыв рынка движка (В.R4б.21, пользователь 13.10): деньги, которые движок теряет внутри частного сектора (покупатели платят за все заказы, продавцы получают за проданное; плюс неистраченный доход населения), — статья карточки кассы предприятий «движок: разрыв рынка и неистраченный доход», а не утечка; сумма — остаток по сохранению денег недели (`zz_ef_f_leak`: скрипт не видит доход населения, разрыв по странам не делится); в отчёте — своя линия рядом с разрывом рынка движка
