# Д.R8в.4 — Платежи клиринга

## Решили

Платежи клиринга: сальдо сводятся сначала внутри группы металла (Д.R8в.2), остаток — между группами; каждый получатель получает от каждого плательщика своей группы долю, пропорциональную их сальдо, — требование на плательщика (вклад в его банках) или металл по своему спросу (Д.R8в.3); общей кассы палаты нет
