# Д.R4б.1 — Кто такой банк

## Решили

Кто такой банк (В.R4б.1, пользователь 12.10): субъекты — по владению уровнями «Банков», мелкое сливается: каждая банковская компания — свой субъект; уровни государства — субъект «госбанки» (своё поведение); уровни частников и мелких владельцев, в том числе их банки за границей, — один субъект «частные банкиры». Любой субъект (компании, банки, частники, фонды) может быть транснациональным — работа и собственность в нескольких рынках продумываются отдельно (R9а, пример — Ротшильды)
