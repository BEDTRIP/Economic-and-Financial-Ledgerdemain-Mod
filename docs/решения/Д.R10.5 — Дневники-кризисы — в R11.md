# Д.R10.5 — Дневники-кризисы — в R11

## Решили

Дневники-кризисы — в R11 (пользователь 17.10): панель дневника шириной ~¼ экрана не растягивается, поэтому кризисы — несколько дневников по областям, делаются вместе с самими кризисами; в R10 старые дневники не трогать

## Статус в реестре

действует, R11 (когда: 17.10)
