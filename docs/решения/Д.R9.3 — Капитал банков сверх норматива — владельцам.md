# Д.R9.3 — Капитал банков сверх норматива — владельцам

## Решили

Капитал банков сверх норматива — владельцам (пользователь 14.10; решает В.R6.15): раз в месяц капитал субъекта сверх норматива (принято ночью: 10 % доходных активов) — компании-банку на её счёт, «частным банкирам» — во вклады населения, «госбанкам» — в казну; денежную массу (M2 / ВВП) сводить в R11; выплата «госбанков» в казну — только из свободных денег пула (Д.R9.9)
