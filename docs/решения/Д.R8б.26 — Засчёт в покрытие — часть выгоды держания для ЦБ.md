# Д.R8б.26 — Засчёт в покрытие — часть выгоды держания для ЦБ

## Решили

Засчёт в покрытие — часть выгоды держания для ЦБ: требование, которое идёт в его покрытие (ЦБ на обменном стандарте, эмитент с разменом), ЦБ сравнивает с металлом (доходность 0), а не с ключевой ставкой; требование вне покрытия — по общей формуле, а при покрытии ниже порога размена ЦБ продаёт его на металл
