# Д.R6.10 — Выход на биржу — IPO

## Решили

Выход на биржу — IPO (пользователь 14.10): при листинге компания продаёт часть своих акций на бирже, деньги покупателей (из их вкладов) — на её счёт; остальные доли — владельцам из населения по категории компании, бесплатно; доля размещения — принять ночью
