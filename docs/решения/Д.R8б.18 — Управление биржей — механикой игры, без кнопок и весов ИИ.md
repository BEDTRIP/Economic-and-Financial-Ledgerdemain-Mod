# Д.R8б.18 — Управление биржей — механикой игры, без кнопок и весов ИИ

## Решили

Управление биржей — механикой игры, без кнопок и весов ИИ: надбавка комиссии на чужие требования — по закону торговой политики (меньше при свободной торговле, больше при протекционизме), изоляционизм — запрет ввоза и вывоза капитала; договор о правах на зарубежные инвестиции, сюзерен–подданный и один рынок — без надбавки; заменяет «управление биржей у государства» [[Д.R8.5 — Комиссия — своя по видам актива|Д.R8.5]]
