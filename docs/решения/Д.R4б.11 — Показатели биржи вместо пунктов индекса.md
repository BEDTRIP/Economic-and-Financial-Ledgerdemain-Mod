# Д.R4б.11 — Показатели биржи вместо пунктов индекса

## Решили

Показатели биржи вместо пунктов индекса (В.R4б.12, пользователь 12.10): пунктов нет — биржи сравнивают между собой по реальным величинам; раз в месяц у биржи — оборот (месяц и 12 месяцев, в золоте; по деньгам и облигациям), сделки, доля оборота из-за границы, комиссия, капитализация требований её участников (стран с этой биржей по маршруту, её фонд среди них) по рынку и по базе без множителей, перегрев = рынок / база, участники, активы стакана, капитал и пай фонда; таблица «Биржи мира» — по обороту за год. Ликвидность и размещения — R5
