# Д.R8в.15 — Глава валютного союза и его валюта

## Решили

Глава валютного союза и его валюта: союз — связные договоры «Монетарная интеграция» (каждый член держит договор с тем, кто был главой при его вступлении); глава — член с наибольшим престижем среди членов с ЦБ ([[Д.R8в.19 — Законы члена валютного союза|Д.R8в.19]]; в союзе блока — лидер блока), смена — как борьба за лидерство в блоке (претендент дольше срока игры обгоняет главу на порог игры, `NPowerBlocs` `POWER_STRUGGLE_*`); при смене главы валюта, стандарт и паритет союза — нового главы, все члены пересчитываются по отношению паритетов (стоимость в золоте не меняется); разрыв договора отделяет всех, кто держался через него: двое и больше — свой союз (глава по престижу, его валюта), один — своя валюта по паритету союза; выход из блока у союза блока — разрыв договоров этой страны, члены блока за ней остаются в союзе блока
