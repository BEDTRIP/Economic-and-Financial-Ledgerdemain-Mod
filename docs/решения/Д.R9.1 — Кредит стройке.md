# Д.R9.1 — Кредит стройке

## Решили

Кредит стройке — по банкам (пользователь 14.10; решает В.R9.1, вариант 2): у каждого субъекта-банка своя ставка по кредиту — ключевая + 3 п. п. + надбавка от его доли капитала в доходных активах (как ставка вкладов субъекта, Д.R4б.2); новый деловой кредит делится по свободному лимиту (Д.R9.2) × привлекательности ставки — дешёвый банк даёт больше; проценты страны — сумма по банкам
