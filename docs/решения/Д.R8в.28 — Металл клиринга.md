# Д.R8в.28 — Металл клиринга

## Решили

Металл клиринга (пользователь 11.10): плательщик отдаёт свой металл, получатель держит тот же, и при смене стандарта, якоре подданного и кризисном выкупе резервы ЦБ не переводятся (серебро не становится золотом; покрытие считает оба по мировой цене, [[Д.R8а.5 — Покрытие — одно число|Д.R8а.5]]); готовность плательщика платить металлом — по лишку покрытия ЦБ над целью (0 на цели, вся при двойной цели), доля — [[Д.R8в.29 — Доля платежа клиринга не в деньгах плательщика — баланс|Д.R8в.29]]; дополняет [[Д.R8в.11 — Платёж клиринга — набор|Д.R8в.11]]
