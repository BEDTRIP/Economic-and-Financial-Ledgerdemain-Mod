# Д.R8б.19 — Биржа — стакан на каждый актив

## Решили

Биржа — стакан на каждый актив (вид × должник) на каждой бирже: продают все держатели актива по своей цене, покупают желающие по своей; раз в неделю — сведение по шагам цены (одна цена расчёта на актив); остаток стакана берёт или отдаёт фонд по своим котировкам в пределах ёмкости; заменяет «держатель торгует только с фондом» [[Д.R8.6 — Держатель меняет требования только с фондом своей биржи|Д.R8.6]] и «лучшая цена среди фондов» [[Д.R8б.5 — Фонд — отдельный вид субъекта|Д.R8б.5]]
