# Д.R8б.21 — Деньги сделки — со счёта самого субъекта

## Решили

Деньги сделки — со счёта самого субъекта: банки — пул, население — вклады, казна — казна, ЦБ — резервы, фонд — свой вклад в банках страны биржи (капитал фонда = вклад; выручка за паи — переводом из пула во вклад фонда); через границу — в поток недели и через клиринг; ответ на В-R8б.1
