# Д.R6.11 — Цена акции

## Решили

Цена акции (пользователь 14.10): цена размещения = годовая чистая прибыль по счёту (приход − проценты) / (ставка правительства + 4 п. п.) (Д2.10); дальше цена — стакан биржи; та же формула × множитель спроса — справедливая цена для решений держателей
