# Д.R8в.7 — Ввод валюты E&F не трогает страну, у которой уже есть валюта и паритет

## Решили

Ввод валюты E&F не трогает страну, у которой уже есть валюта и паритет (закон, паритет, резервы остаются — новый ЦБ начинает с ними); ввод с паритетом — только стране без денежной системы, паритет — от денег, ходивших на её земле (паритет прежнего эмитента × его курс); дальше курс двигает биржа. Скачок Ганновера 3,32 → 18,9 — случайный паритет 15–30 скрипта ввода E&F
