# Д.R8в.11 — Платёж клиринга — набор

## Решили

Платёж клиринга — набор (пользователь 10.10): n % валютой плательщика (у получателя — требование на плательщика), n растёт с силой валюты плательщика и доверием к ней (у эталона больше); остаток — по стандарту получателя: металлический — металлом из резервов плательщика (не хватает — валютой получателя); обменный и фиат — валютой получателя: сначала из резервов плательщика в ней, потом покупка на бирже; не купленное — долг недели, требование получателя на плательщика. Металл ездит только к металлическим стандартам (заменяет Д.R8в.3, Д.R8в.10)
