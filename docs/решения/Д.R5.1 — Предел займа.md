# Д.R5.1 — Предел займа

## Решили

Предел займа (пользователь 12.10): реальный — финансовые резервы зданий + свободные вклады банков (вклады − выданные кредиты); предел игры — внешняя граница дефолта, его доля ВВП (`COUNTRY_MIN_CREDIT_SCALED`, общая для всех стран) уменьшена по прогону так, чтобы в среднем быть близкой к реальному; займ сверх реального — недостающее банки берут кредитом ЦБ (выпуск под долг), без ЦБ при металлическом — занять негде, только рост ставки
