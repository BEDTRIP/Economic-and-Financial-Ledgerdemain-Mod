# Д.R9.2 — Лимит кредита — у каждого банка свой

## Решили

Лимит кредита — у каждого банка свой (пользователь 14.10; решает В.R9.2): кредиты субъекта не больше капитала × плечо, плечо растёт при низкой ключевой ставке и падает при высокой (коэффициенты — принято ночью); свободный лимит банков страны — рычаг частной стройки: его нет — доля частной стройки падает
