# Д.R8в.5 — Валютный союз — общая валюта

## Решили

Валютный союз — общая валюта: каждый ЦБ члена выпускает её по общему паритету (одна `var:zz_ef_cur`), покрытие — по союзу целиком (металл всех ЦБ / денежная масса союза), ключевая ставка одна — её ведёт глава союза (Д.R8в.14); платежи между членами — без клиринга и биржи, как внутри одного рынка; вступление — статьёй договора (Д.R8в.13), вышедший член получает свою валюту по паритету союза на день выхода
