# Д.R8в.6 — Дивиденды через границу

## Решили

Дивиденды через границу: ВВП во владении иностранцев (мост бюджета) × доходность капитала страны, где стоят здания (прибыль её бизнеса / её ВВП); получатель — владелец, плательщик — страна зданий; допущение «15 % ВВП владения» снимается
