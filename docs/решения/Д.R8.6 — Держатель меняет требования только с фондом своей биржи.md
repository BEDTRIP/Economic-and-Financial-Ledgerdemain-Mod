# Д.R8.6 — Держатель меняет требования только с фондом своей биржи

## Решили

Держатель меняет требования только с фондом своей биржи; маршрут без финцентра — хозяин рынка → лидер блока → сильнейший блок → мировая; фонд — ПИФ E&F; ненужность — из выгоды без порогов; торги — в день шага, заявки игрока — сразу
