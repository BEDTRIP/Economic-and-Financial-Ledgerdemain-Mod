# Д.R8в.13 — Валютный союз — один механизм, статья договора «Монетарная интеграция»

## Решили

Валютный союз — один механизм, статья договора «Монетарная интеграция» (`common/treaty_articles`) между любыми двумя странами с хорошими отношениями: вступление в союз главы (договор с главой — членство со всеми членами, остальные члены не голосуют); нет союза ни у кого — договор основывает его; торг — обычным договором игры (законы, области, деньги); согласие ИИ — слагаемые (база, отношения, доля торговли с главой, группа металла, сила своей валюты, великая держава); 3-й уровень принципа «Объединение рынков» у лидера блока — сильный плюс к согласию членов блока и запись дневника «Монетарный союз» (выпуск и запасы валюты союза по странам, покрытие, кто из блока не присоединился); выход из блока у союза блока — без таможенного союза и валюты, разрыв договора — своя валюта по паритету союза; Латинский и Скандинавский — исторический толчок (Франция с 1860, Швеция с 1873 охотно предлагают статью странам из списков E&F), записи и события переговоров E&F — в `_archive/`
