# Д.R6.7 — Счёт компании

## Решили

Счёт компании (пользователь 14.10; заменяет [[Д.R6.2 — Счёт компании|Д.R6.2]]): компания — субъект модели со своим счётом — вкладом в банках страны (переменная на компании; сумма по стране — вклады компаний `zz_ef_comp_dep` книги банков, в M2 как вклады); касса зданий — деньги игры (скрипт её не двигает, `script_docs`), в балансе компании — только для показа (доля по уровням). Приход: взносы игры в пул делятся по доле уровней — компании / все частные уровни — на счета компаний, остальное — во вклады населения; кредит банков ([[Д.R6.9 — Кредит компаний|Д.R6.9]]); продажа акций ([[Д.R6.10 — Выход на биржу — IPO|Д.R6.10]]); доля компаний в возврате сгоревшего. Частный сектор вне компаний — собиратель страны
