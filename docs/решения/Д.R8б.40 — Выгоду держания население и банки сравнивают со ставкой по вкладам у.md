# Д.R8б.40 — Выгоду держания население и банки сравнивают со ставкой по вкладам у

## Решили

Выгоду держания население и банки сравнивают со ставкой по вкладам у себя дома (куда легли бы деньги иначе), казна и ЦБ вне покрытия — с ключевой ставкой, ЦБ для покрытия — с металлом; капитал течёт туда, где ставки выше (дополняет В-R8б.2: при ключевой ставке покупателей не было)
