# Д.R10.3 — Верхняя панель — четыре показателя

## Решили

Верхняя панель — четыре показателя (пользователь 17.10; M2 / ВВП, госдолг / ВВП — в подсказке покрытия, не отдельно): курс, покрытие ЦБ, ключевая ставка, оборот биржи с флагом биржи (своя или чья); подсказка курса — только курс, счета ЦБ — в подсказку покрытия; клик по показателю открывает его окно; встраивание — через ETF, не копией `topbar.gui`
