# Д.R9б.7 — Методы владения штабов компаний — INJECT

## Решили

Методы владения штабов компаний — `INJECT:` только `building_modifiers` E&F (пользователь 16.10; решает В.R9б.9, вариант 1): условия ванили (категории компании, законы, принципы, иконка, скрытие недоступного) остаются; E&F меняет только найм и доли владельцев. Если `INJECT:` не заменяет блок `building_modifiers`, а дописывает его (ванильные числа останутся рядом с E&F) — полное тело ванили + числа E&F (вариант 2)
