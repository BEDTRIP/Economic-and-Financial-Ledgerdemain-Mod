# Д.R9б.1 — Здание ЦБ E&F building_bank — в архив

## Решили

Здание ЦБ E&F `building_bank` — в архив (пользователь 14.10; решает В.R9б.1, вариант 1; исполняет [[Д.R4а.9 — ЦБ без «Банков»|Д.R4а.9]], [[Д.R5.11 — Здание ЦБ E&F building_bank|Д.R5.11]]): признак «у страны есть ЦБ» — модификатор `has_central_bank`, не здание; размер ЦБ по ВВП (переключатель `macro_facilities_bc`) — значением скрипта; чеканка — модификатором страны при законе стандарта (величина метода стандарта × размер ЦБ), ±25 % ревальвации и девальвации — законами денежной политики; товар «облигации» выпускают здания «Банк» (`building_zz_ef_bank`) с тем же сдвигом по долгу / ВВП и тем же выпуском страны; база закупки металла денежной властью (`zz_ef_cb_base_g` / `_s`) — величина метода стандарта × размер ЦБ; рабочих мест ЦБ не переносить
