# Д.R4а.7 — Ставка по вкладам — не выше дохода банков за вычетом маржи

## Решили

Ставка по вкладам — не выше дохода банков за вычетом маржи: min(ставка вкладов, (проценты по кредитам + доход «Банков») / вклады − маржа); нехватку ликвидности банки покрывают кредитом ЦБ (пользователь 11.10) — капитал банков не уходит в минус от процентов
