# Реестр механизмов

Каждый механизм E&F (и подозрительные места PSC / `ld_*`) — с состоянием. Основа уборки: удаляется только `мёртвый` и
`выключен` (вместе с вызовами и интерфейсом); `дубль` и живое, которое пишет в счета модели `ld_*` мимо неё, — решение
пользователя. После удаления механизма — убрать строку отсюда и поправить документ подсистемы.

Статусы: `живой` — вызывается и влияет на игру; `выключен` — вызывается, но заглушен (пустое тело, нулевой
коэффициент, закомментированный вызов); `мёртвый` — ни откуда не вызывается; `дубль` — считает то же или пишет те же
счета, что модель `ld_*`. Строки файлов — на момент записи, при правке файла сдвигаются: искать по имени.

Итого: мёртвый 4, выключен 0, дубль 3, живой 218.
