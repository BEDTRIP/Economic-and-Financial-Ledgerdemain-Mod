# Консоли

## Подсказка

Консоли — бессрочные [[Облигации|облигации]] [[Казна|казны]], которые [[Центральный банк|центральный банк]] продаёт [[Группа населения|населению]]: казна не возвращает этот долг, но платит по нему [[Проценты|проценты]] в сбережения населения, пока долг существует. Излишки казны идут на выкуп консолей обратно.

## Рабочее

### Целевое значение

Облигации ЦБ, проданные населению, — бессрочный долг населению того, чей ЦБ (Д.R9б.12): казны при государственном ЦБ,
компании-ЦБ при частном и внешнем (проценты и выкуп — из её счёта). Продажа — долг; проценты — казна → сбережения
населения (банкноты, [[Денежная масса|M0]]); выкуп из излишка казны.

### Что в коде

Сделано: долг казны; при частном ЦБ — долг компании-ЦБ (Д.R9б.12, R9б.14): проценты и выкуп — с её счёта во вклады
населения (выкуп — счёт сверх годовых процентов, за год — принято ночью). `ld_consols.txt`, `docs/код/bonds.md`.
