# Проценты в форке

Понятие игры — [[Проценты]]; здесь — как им пользуется форк: своё поверх чужого — своя заметка, граф игры описывает
только игру.

## Рабочее

Ставка процентов по займам казны в модели — от [[Ставка ЦБ|ставки ЦБ]] плюс [[Премия за риск|премия за риск]]; проценты
получают держатели [[Облигации|облигаций]] деньгами из [[Казна|казны]].
