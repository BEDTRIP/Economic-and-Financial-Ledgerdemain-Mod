# Член блока государств в форке

Понятие игры — [[Член блока государств]]; здесь — как им пользуется форк: своё поверх чужого — своя заметка, граф игры
описывает только игру.

## Рабочее

Член блока вступает в [[Валютные союзы|валютный союз]] лидера договором «Монетарная интеграция» ([[Д.R8в.13 — Валютный союз — один механизм, статья договора «Монетарная интеграция»|Д.R8в.13]]); выход из
блока лишает его таможенного союза и валюты союза ([[Д.R8в.15 — Глава валютного союза и его валюта|Д.R8в.15]]).
