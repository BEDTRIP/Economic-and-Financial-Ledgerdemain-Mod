# Золотой запас в форке

Понятие игры — [[Золотой запас]]; здесь — как им пользуется форк: своё поверх чужого — своя заметка, граф игры описывает
только игру.

## Рабочее

Золотой запас игры — деньги [[Казна|казны]] в модели: счёт казны и есть он (`gold_reserves`), модель раскладывает его
изменения [[Проводка|проводками]]. С [[Металл|металлом]] денежной системы (резервы [[Центральный банк|ЦБ]], банков,
населения) он не связан.
