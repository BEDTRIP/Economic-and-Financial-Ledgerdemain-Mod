# Клиринг

## Подсказка

Клиринг — расчёты вашей [[Страна|страны]] с заграницей за неделю. Внешние потоки — [[Торговля с заграницей|торговля]], доходы и платежи за рубежом, [[Дивиденды через границу|дивиденды]], [[Облигации|облигации]] — сводятся в чистую позицию страны. Должник платит своим получателям [[Металл|металлом]] или [[Требование|требованиями]] — своими деньгами и долгами, а получатель продаёт ненужное на [[Биржа|бирже]]. Сначала долги гасятся между странами одного металла ([[Зачёт по группам металла]]), и только остаток идёт через биржу.

Платёж — набор, и его состав — торг. Получатель хочет металла (или своей валюты) тем больше, чем меньше доверяет деньгам плательщика и чем ниже его собственное [[Покрытие|покрытие]]; плательщик отдаёт металл, только если его покрытие выше цели, а ниже половины цели не отдаёт его даже крупному получателю — платит долгом, как при приостановке размена. Чья экономика больше, тот и диктует. Часть, оплаченная деньгами плательщика, лежит у получателя вкладом в банках плательщика. Остальное — по [[Денежный стандарт|стандарту]] получателя: [[Металлический стандарт|металлическому]] — [[Металл|металлом]] из резервов плательщика, тем металлом, который у него есть (серебро остаётся серебром и идёт в покрытие получателя по мировой цене); [[Обменный стандарт|обменному]] и [[Фиат|фиату]] — валютой получателя из резервов плательщика. Чего не хватило, плательщик остаётся должен и докупает валюту получателя на [[Биржа|бирже]].

[[Страна]] [[Без денежной системы|без денежной системы]] в клиринге не участвует — её платежи идут мировым счётом. [[Субъект|Подданные]] рассчитываются сами, а страны одного [[Рынок|рынка]] — и между собой ([[Один рынок]]).

## Рабочее

### Целевое значение

**Цель (R8в):** кассы нет — должник платит конкретным получателям набором (своя валюта, валюта получателя, металл
металлическому стандарту; [[Д.R8в.11 — Платёж клиринга — набор|Д.R8в.11]]); ненужное продаётся на бирже; чистая позиция у каждого; расчёты внутри рынка
([[Д.R8в.1 — Страны в одном рынке — позиция члена по долям рынка|Д.R8в.1]]); безвалютные — мировой строкой.

**Платежи ([[Д.R8в.4 — Платежи клиринга|Д.R8в.4]]).** Сальдо недели сводятся сначала внутри группы металла ([[Зачёт по группам металла]], [[Д.R8в.2 — Зачёт по группам металла|Д.R8в.2]]),
остаток — между группами через биржу по мировой цене с комиссией. Внутри группы каждый получатель получает от каждого
плательщика долю, пропорциональную их сальдо.

**Платёж — набор ([[Д.R8в.11 — Платёж клиринга — набор|Д.R8в.11]]).** n % — валютой плательщика: у получателя это требование на плательщика (вклад в его
банках); n растёт с силой валюты плательщика и доверием к ней, у [[Эталонная валюта|эталона]] больше. Остаток — по
стандарту получателя: [[Металлический стандарт|металлическому]] — металлом из резервов плательщика (не хватает — валютой
получателя); [[Обменный стандарт|обменному]] и [[Фиат|фиату]] — валютой получателя: сначала из резервов плательщика в
ней, потом покупка на [[Биржа|бирже]] — так спрос на чужие деньги идёт от торговли; не купленное — долг недели. Металл
ездит только к металлическим стандартам, как в XIX веке: остаток сальдо везли золотом, а страны обменного стандарта
держали расчёты в разменной валюте. Члены [[Валютные союзы|валютного союза]] между собой не рассчитываются — деньги одни
([[Д.R8в.5 — Валютный союз — общая валюта|Д.R8в.5]]).

### Что в коде

Сделано (R8в, шаг 2): `ld_clearing.txt`. За неделю внешние потоки страны (торговля, доходы и платежи за рубежом,
дивиденды, облигации, биржа) сводятся в позицию в золоте (`var:zz_ef_clr_pos`); в конце недели (`zz_ef_clr_settle`)
позиции сводятся внутри групп металла (золото, серебро, биметалл по законному соотношению, фиат; обменный — группа
своего металла) — каждый плательщик группы платит каждому получателю долю, пропорциональную их позициям; остатки групп —
между группами, насколько остатки мира совпадают, минус комиссия биржи плательщика; не совпавшее миром не сводится
(карточка — «не сведено клирингом»). Платёж — набор: доля 1 − доля металла по силе валюты (слабая — 0, сильная — 70 %,
эталон — 85 %) — спрос получателя (у ЦБ металлического стандарта ниже цели покрытия — больше), предложение плательщика —
по лишку его покрытия над целью (0 на цели, всё при двойной); доля металла — их среднее с весом ВВП сторон ([[Д.R8в.28 — Металл клиринга|Д.R8в.28]],
[[Д.R8в.29 — Доля платежа клиринга не в деньгах плательщика — баланс|Д.R8в.29]]); остальное — требованием получателя на плательщика; остаток металлическому стандарту — металлом из резервов
плательщика, тем же металлом (серебро не становится золотом; [[Д.R8в.28 — Металл клиринга|Д.R8в.28]]); затем валютой получателя из резервов
плательщика; остаток — долг недели (тоже требование на плательщика), а плательщик на следующем шаге ставит заявку на
покупку валюты получателя по верхнему шагу своей биржи. [[Денежная власть]] — ЦБ (металл в столичном штате ЦБ, требования
`cb`), без ЦБ — банки (`bk`). Палаты и главы нет; подданные рассчитываются сами; страны без своих денег — мировая строка
(`global_var:zz_ef_clr_wl`, лог `EFN`). Принято ночью, проверить: доля эталона 85 %; комиссия между группами просто не
доходит до получателя (никому не платится); биметалл платит металлом ЦБ (золотом), а не переоценённым законом металлом
(Грешем — вопрос). [[clearing-fx]].
