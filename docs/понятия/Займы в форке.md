# Займы в форке

Понятие игры — [[Займы]]; здесь — как им пользуется форк: своё поверх чужого — своя заметка, граф игры описывает только
игру.

## Рабочее

Займы казны в модели — [[Облигации|облигации]]: долг казны игры разложен по держателям — [[Банки|банкам]],
[[Группа населения|населению]], [[Центральный банк|ЦБ]], казнам других стран, [[Инвестиционный фонд|фондам]]; заграница
— через [[Клиринг|клиринг]]. Проценты и погашение идут деньгами между держателями и [[Казна|казной]], а не «из воздуха».
Цена займов — [[Ставка ЦБ|ставка ЦБ]] плюс [[Премия за риск|премия за риск]].
