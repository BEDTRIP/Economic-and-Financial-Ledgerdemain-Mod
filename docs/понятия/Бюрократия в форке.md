# Бюрократия в форке

Понятие игры — Бюрократия; здесь — как им пользуется форк: своё поверх чужого — своя заметка, граф игры описывает
только игру.

## Рабочее

Коррупция в форке отдельно не заводится: её роль играет нехватка бюрократии ([[Принципы мода|принцип 14]]).
