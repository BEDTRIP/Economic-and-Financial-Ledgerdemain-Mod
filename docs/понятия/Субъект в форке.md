# Субъект в форке

Понятие игры — [[Субъект]]; здесь — как им пользуется форк: своё поверх чужого — своя заметка, граф игры описывает
только игру.

## Рабочее

Подданный с денежной системой может перейти на [[Внешневалютный стандарт|внешневалютный стандарт]]: его деньги привязаны
к валюте сюзерена, сюзерен — его [[Якорь|якорь]] (металл, курс, ставка).

Подданный и сюзерен торгуют [[Требование|требованиями]] друг на друга без надбавки торговой политики к
[[Комиссия биржи|комиссии биржи]] (Д.R8б.18).
