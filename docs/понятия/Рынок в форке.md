# Рынок в форке

Понятие игры — [[Рынок]]; здесь — как им пользуется форк: своё поверх чужого — своя заметка, граф игры описывает только
игру.

## Рабочее

Несколько стран в одном рынке — [[Один рынок]]: позиция каждой — по её долям в производстве и потреблении рынка
([[Д.R8в.1 — Страны в одном рынке — позиция члена по долям рынка|Д.R8в.1]]). Торговля с заграницей меряется по рынку ([[Торговля с заграницей]]).

Страны одного рынка торгуют [[Требование|требованиями]] друг на друга без надбавки торговой политики к
[[Комиссия биржи|комиссии биржи]] ([[Д.R8б.18 — Управление биржей — механикой игры, без кнопок и весов ИИ|Д.R8б.18]]).
