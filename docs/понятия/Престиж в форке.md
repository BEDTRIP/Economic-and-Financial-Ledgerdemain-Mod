# Престиж в форке

Понятие игры — [[Престиж]]; здесь — как им пользуется форк: своё поверх чужого — своя заметка, граф игры описывает
только игру.

## Рабочее

Глава [[Валютные союзы|валютного союза]] вне блока — член с наибольшим престижем; смена главы — как борьба за лидерство
в блоке, союз переходит на валюту нового главы (Д.R8в.15).
