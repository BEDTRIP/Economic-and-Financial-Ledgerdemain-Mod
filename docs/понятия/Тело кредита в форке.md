# Тело кредита в форке

Понятие игры — Тело кредита; здесь — как им пользуется форк: своё поверх чужого — своя заметка, граф игры описывает
только игру.

Тело кредита игры — сумма, которую модель раскладывает по держателям [[Облигации|облигаций]].
