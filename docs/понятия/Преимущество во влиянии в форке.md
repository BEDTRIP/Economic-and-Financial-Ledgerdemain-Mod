# Преимущество во влиянии в форке

Понятие игры — [[Преимущество во влиянии]]; здесь — как им пользуется форк: своё поверх чужого — своя заметка, граф игры
описывает только игру.

## Рабочее

Страна без своей [[Биржа|биржи]] и вне блока торгует на бирже лидера блока с наибольшим влиянием на неё: движок даёт
влияние блока только как преимущество, а у самого влиятельного блока оно наибольшее и тогда, когда отрицательное (его
перевешивает невостребованное влияние страны). Блоку без влияния на страну движок даёт 0, а не минус, — такой блок не в
счёт. Нет такого — биржа владельца рынка, иначе мировая (маршрут биржи, [[Д.R8в.22 — Маршрут биржи без своего финцентра|Д.R8в.22]]).
