# Компания в форке

Понятие игры — [[Компания]]; здесь — как им пользуется форк: своё поверх чужого — своя заметка, граф игры описывает
только игру.

## Рабочее

Каждая компания — отдельный [[Субъекты|субъект]] модели с целью «прибыль» (у стран [[Роли стран|роли]] Б — агрегат): у
неё свой баланс, она берёт кредит в [[Банки|банках]], может выйти на [[Биржа|биржу]] и обанкротиться.

### Целевое значение

| баланс | что |
| --- | --- |
| активы | здания (уровни по оценке), касса зданий (вклады в банках) — только деньги |
| пассивы | кредиты банков, акции (если публичная) |

**Решения:** расширяться в кредит; стать публичной (листинг на бирже страны, места — по уровням [[Финцентр|финцентра]]);
продавать здания вне своих типов и при нехватке денег на проценты (пересоздание на покупателя). Банкротство —
[[Банкротство]].

Счёт компании — её вклад в банках страны ([[Д.R6.7 — Счёт компании|Д.R6.7]]): приход — взносы игры в пул по доле её уровней среди частных, кредит
банков (деловой кредит страны по доле уровней, [[Д.R6.9 — Кредит компаний|Д.R6.9]]; частная стройка — из кредита, не из вкладов населения, [[Д.R6.13 — Частная стройка — из делового кредита|Д.R6.13]]),
продажа акций, доля возврата сгоревшего; расход — проценты и погашение, дивиденды раз в месяц сверх нормы счёта —
держателям акций и владельцам из населения ([[Д.R6.8 — Дивиденды|Д.R6.8]]). Касса зданий — деньги игры: скрипт её не двигает, в балансе
компании — только для показа. Акции — поштучно, один тип ([[Д.R6.3 — Акции поштучно|Д.R6.3]]); выход на биржу — IPO: компания продаёт часть акций,
деньги — на её счёт, остальное — владельцам из населения ([[Д.R6.10 — Выход на биржу — IPO|Д.R6.10]]); цена размещения — чистая прибыль / (ставка
правительства + 4 п. п.), дальше — стакан ([[Д.R6.11 — Цена акции|Д.R6.11]]); банки — компании, паи фондов — акции фонда. Частный сектор вне
компаний — собиратель страны. Выкупленный игрой уровень оплачивается продавцу ([[Д.R6.1 — Выкуп уровней — продавцу|Д.R6.1]]). Банкротство E&F
`bankrupt_company` — в архиве (`_archive/ef_bankrupt_company/`), своё — R11 ([[Д.R6.4 — Банкротство компании|Д.R6.4]]). Методы владения
[[Офис компании|офиса]] — с условиями игры (категория компании, законы, принципы); форк меняет только найм и доли
владельцев ([[Д.R9б.7 — Методы владения штабов компаний — INJECT|Д.R9б.7]]).

### Что в коде

Сделано: счёт компании (R6.2) — `zz_ef_co_acc` на компании, вклады компаний страны = счета + собиратель; приход — доля
взносов в пул и возврата сгоревшего по уровням ([[exchange-companies]], «Счёт компании»); доля кассы зданий по
уровням — только для показа в логе (`EFJ|…|comp`). Кредит (R6.3): деловой кредит страны — компаний по уровням, их доля
обслуживания — со счетов, отметка «не может платить» (`zz_ef_co_distress`); частная стройка — из кредита. Дивиденды
(R6.4): раз в месяц счёт сверх трёх месяцев расхода — во вклады населения (владельцы — одним агрегатом). Акции (R6.6):
при первом листинге — IPO (акций — на капитализацию по справедливой цене, четверть — на продажу в стакан биржи её
страны, остальное — населению страны), цена — чистая прибыль года / (ставка правительства + 4 п. п.) × множитель
стакана, торги населения и банков, дивиденды держателям по доле ([[exchange-companies]], «Акции»). Нет:
капитализация биржи по акциям, своё банкротство — R6.7, R11; методы владения офиса — пока `REPLACE:` E&F без условий
игры (у любого офиса открыты все методы), [[Д.R9б.7 — Методы владения штабов компаний — INJECT|Д.R9б.7]] — R9б.18.
