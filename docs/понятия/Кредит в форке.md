# Кредит в форке

Понятие игры — [[Кредит]]; здесь — как им пользуется форк: своё поверх чужого — своя заметка, граф игры описывает только
игру.

Лимит кредитования игры модель не меняет; кто именно кредитует казну, показывает реестр [[Облигации|облигаций]].
