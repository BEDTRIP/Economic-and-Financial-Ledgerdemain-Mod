# Лоялист в форке

Понятие игры — [[Лоялист]]; здесь — как им пользуется форк: своё поверх чужого — своя заметка, граф игры описывает
только игру.

## Рабочее

Доля лоялистов — основа [[Доверие к деньгам|доверия к деньгам]]: довольные положением дел пользуются финансовой системой
страны полностью — вклады, облигации, паи ([[Д.R7.1 — Доверие к деньгам — не отдельная ручка|Д.R7.1]], форма — R7).
