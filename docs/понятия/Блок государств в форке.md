# Блок государств в форке

Понятие игры — [[Блок государств]]; здесь — как им пользуется форк: своё поверх чужого — своя заметка, граф игры
описывает только игру.

## Рабочее

Основать блок государств может только страна со своей [[Биржа|биржей]] ([[Финцентр]], Д.R8.7). Члены блока без своей
биржи и без биржи у владельца рынка торгуют на бирже лидера блока.
