# Благосостояние в форке

Понятие игры — [[Благосостояние]]; здесь — как им пользуется форк: своё поверх чужого — своя заметка, граф игры
описывает только игру.

## Рабочее

Потери [[Группа населения|населения]] от краха [[Биржа|биржи]], банкротства [[Банки|банка]], дефолта и
[[Девальвация и ревальвация|девальвации]] списываются с благосостояния попов — по потреблению финансовых товаров,
богатые теряют больше. Это один из [[Рычаги на движок|рычагов]] модели на игру (`add_pop_wealth`); сделано для падения
цены требований населения на бирже (R7.6, `ld_holder_losses.txt`), остальное — нет.
