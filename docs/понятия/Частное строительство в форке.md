# Частное строительство в форке

Понятие игры — [[Частное строительство]]; здесь — как им пользуется форк: своё поверх чужого — своя заметка, граф игры
описывает только игру.

## Рабочее

Частное строительство из [[Инвестиционный пул|пула]] модель считает кредитом [[Банки|банков]] компаниям. Его рычаг —
модификатор от [[Ставка ЦБ|ставки ЦБ]] и свободного пула ([[Рычаги на движок]]); с R9 ([[Д.R9.1 — Кредит стройке|Д.R9.1]], [[Д.R9.2 — Лимит кредита — у каждого банка свой|Д.R9.2]]) кредит выдают
банки по своим ставкам и лимитам — нет свободного лимита у банков страны, доля частной стройки падает.
