# Технология в форке

Понятие игры — [[Технология]]; здесь — как им пользуется форк: своё поверх чужого — своя заметка, граф игры описывает
только игру.

## Рабочее

**Финансовые технологии снижают [[Комиссия биржи|комиссию биржи]]** ([[Д.R8.5 — Комиссия — своя по видам актива|Д.R8.5]]). База — 0,5 % сделки; каждая из шести
технологий страны биржи — «Фондовая биржа», «Акционерные компании», «Инвестиционные банки», «Паевые инвестиционные
фонды», «Стандарты международного обмена», «Современные финансовые инструменты» — снимает 15 % базы, не ниже 10 % базы
(0,05 %). Технология финансового центра — условие [[Финцентр|учреждения биржи]]. В описании технологий игры это пока не
показано — R10.

### Что в коде

`zz_ef_xch_fee_v` (`ld_exchange_values.txt`); взимание — с покупателя в сделке стакана (`ld_exchange_trade.txt`), доход
— владельцам финцентра.
