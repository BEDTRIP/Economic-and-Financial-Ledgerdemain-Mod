# Карта понятий «E&F: Ledgerdemain»

Одна заметка — одно понятие мода: «Подсказка» — текст будущей подсказки в игре со ссылками на все термины; «Рабочее» —
«Целевое значение» (правила, решения, открытые вопросы) и «Что в коде». Решения — по номерам в `docs/решения/`; код —
документы `docs/`; открытые задачи — [[план]] и этапы узла.

Понятия самой игры — граф ваниль, [[_Карта ванили]] (`vic3_mods_out/docs/vanilla/`): он описывает только игру. Как форк
пользуется понятием игры — заметка «<понятие> в форке» (`uses` — на заметку игры), группа ниже.
