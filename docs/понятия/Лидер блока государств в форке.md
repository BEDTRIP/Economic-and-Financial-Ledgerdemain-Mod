# Лидер блока государств в форке

Понятие игры — [[Лидер блока государств]]; здесь — как им пользуется форк: своё поверх чужого — своя заметка, граф игры
описывает только игру.

## Рабочее

Страна без своей [[Биржа|биржи]], у владельца рынка которой биржи нет, торгует на бирже лидера своего блока (маршрут
биржи, [[Д.R8.6 — Держатель меняет требования только с фондом своей биржи|Д.R8.6]]). Блок можно основать только со своей биржей ([[Финцентр]], [[Д.R8.7 — Биржа одна на страну, учреждается записью дневника|Д.R8.7]]). Лидер блока — глава
[[Валютные союзы|валютного союза]] внутри блока ([[Д.R8в.15 — Глава валютного союза и его валюта|Д.R8в.15]]); с технологией союзов у него запись дневника «Монетарный союз
блока» ([[Д.R8в.18 — Запись дневника «Монетарный союз блока» — у лидера блока с|Д.R8в.18]]), принцип «Объединение рынков» 3-го уровня облегчает согласие членов ([[Д.R8в.13 — Валютный союз — один механизм, статья договора «Монетарная интеграция»|Д.R8в.13]]).
