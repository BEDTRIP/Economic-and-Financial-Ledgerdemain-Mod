# Стратегическая близость

Стратегическая близость используется для проверки близости двух [[Страна|стран]] и при выполнении ряда условий открывает доступ к определённым взаимодействиям. Две страны считаются стратегически близкими, если выполняется одно из условий:
- У них есть общая граница
- У них есть общая граница с одним [[Морской узел|морским узлом]] между ними
- Одна страна граничит с [[Субъект|субъектом]] другой
- Субъект одной страны граничит с субъектом другой
- Одна страна граничит с ненавязанной [[Цель войны|целью войны]]
