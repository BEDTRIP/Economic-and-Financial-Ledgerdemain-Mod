# Срок исполнения обязательств

У [[Договор|договора]] обычно есть срок исполнения обязательств, в течение которого разрыв договора любой из [[Страна|стран]] приведёт к штрафам для неё. По истечении этого срока расторжение договора более не влечёт за собой штрафов.
