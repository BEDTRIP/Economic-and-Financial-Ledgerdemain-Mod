# Лимит призыва

Максимальное количество [[Батальон призывников|батальонов призывников]], которые можно набрать в [[Область|области]]. Лимит призыва вычисляется как произведение [[Рабочая сила|рабочей силы]] области и доли призывников. Он не может превышать максимальный лимит призыва, который определяется [[Закон|законом]] «Модель армии».
