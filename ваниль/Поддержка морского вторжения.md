# Поддержка морского вторжения

Поддержка морского вторжения — это отношение количества [[Корабль|кораблей]], приписанных к морскому вторжению, к количеству [[Батальон|батальонов]], участвующих во вторжении. Чтобы избежать штрафов при высадке, на каждый батальон должен приходиться один корабль.
