# Мирный договор

Когда [[Военный лидер|военный лидер]] хочет завершить [[Война|конфликт]], он может предложить мирный договор. Для вступления в силу договор должны подписать все оставшиеся договороспособные участники войны. Лидер может добавлять и убирать [[Цель войны|пункты договора]], чтобы сделать его более привлекательным для обеих сторон.
