# Трансфер инвестиционного пула

Когда [[Деньги|деньги]] из [[Казна (ваниль)|казны]] расходуются на [[Строительство|строительство]] [[Сооружение|сооружений]], которые Экономическая система [[Страна|страны]] позволяет финансировать из [[Инвестиционный пул|инвестиционного пула]], расходы казны компенсируются переводом из инвестиционного пула в эквивалентном размере.
