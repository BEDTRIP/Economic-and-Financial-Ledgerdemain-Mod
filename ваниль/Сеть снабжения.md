# Сеть снабжения

Каждой морской [[Страна|державе]] требуется наличие на [[Рынок|рынке]] торговые корабли, которые обслуживают её [[Маршрут поставок|маршруты поставок]]. Сила вашей сети снабжения зависит от количества доступных торговые корабли в сравнении с общими потребностями всех маршрутов поставок. Сила сети определяет [[Эффективность маршрута поставок|эффективность]] маршрутов поставок.
