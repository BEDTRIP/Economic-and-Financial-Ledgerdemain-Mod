# Допущенные страны

Определяет, на какие [[Страна|страны]] действуют ограничения на [[Доступ к проливам|доступ к проливу]], если судоходство **ограничено для военных** или **закрыто**.

**Контролёр может установить следующие ограничения:**
**Все, кроме врагов**
Доступ ограничивается только для кораблей, принадлежащих враждебным [[Контроль над проливами|контролёру]] странам

**Только союзники**
Ограничения затрагивают все суда, кроме кораблей союзников контролёра

**Только владельцы**
Только корабли контролёра и его [[Субъект|субъектов]] могут пользоваться проливом без ограничений
