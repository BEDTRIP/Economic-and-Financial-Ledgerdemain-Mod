# Беспорядки

[[Область|Области]] и [[Культура|культуры]], склонные к беспорядкам, порождают [[Радикал|радикалов]], недовольных текущим положением дел. Уровень беспорядков равен количеству радикальных представителей [[Рабочая сила|рабочей силы]] этой области культуры.

Высокий уровень беспорядков может привести к ряду негативных последствий для области. [[Культурная революция]] может иметь разрушительные последствия для всей [[Страна|страны]].
