# Союзник

Союзником считается [[Страна|страна]], заключившая [[Союз|союз]] или [[Оборонительный пакт|оборонительный пакт]] с другой страной. Союзников можно просить о поддержке в [[Дипломатическая игра|дипломатических играх]]. Для [[Инициатор|инициатора]] союзниками в [[Дипломатическая игра|дипломатической игре]] считаются только [[Страна|страны]], с которыми заключён полноценный [[Союз|союз]].
