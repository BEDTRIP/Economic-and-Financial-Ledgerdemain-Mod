# Канал

Канал — это [[Сооружение|сооружение]], искусственно соединяющее два морских узла по суше. Каналы можно строить только в определённых местах, и обычно для начала строительства нужно провести топографические измерения или экспедицию. Каналы могут значительно сократить расстояния, которые торговые корабли приходится преодолевать для создания [[Маршрут поставок|маршрутов поставок]], что значительно упрощает торговлю с дальними землями.
