# Военные репарации

Дополнительная [[Цель войны|цель войны]], которой можно дополнить [[Дипломатическая игра|дипломатическую игру]]. Для этого выберите соответствующий ей [[Пункт|пункт]] для включения в [[Мирный договор|мирный договор]]. При навязывании данного пункта будет создан новый [[Договор|договор]] со всеми [[Пункт|пунктами]], касающимися военных репараций второй [[Страна|страны]], минимальный срок действия которого равен продолжительности [[Перемирие|перемирия]].
