# Потребительский налог

[[Налоги|Налог]], собираемый с определённых [[Товар|товаров]], приобретаемых [[Группа населения|населением]] для удовлетворения своих [[Потребности группы населения|потребностей]]. Каждый товар, обложенный потребительским налогом, расходует определённое количество [[Авторитет|авторитета]]. Применительно к товару потребительский налог увеличивает его [[Рыночная цена|рыночную цену]] на соответствующий процент, но только для групп населения, и добавочная стоимость всех созданных таким образом [[Приказы о покупке|приказов о покупке]] поступит в [[Казна (ваниль)|казну]]. Поскольку добавочная стоимость применяется на уровне [[Рынок|рынка]], налог неэффективен в [[Область|областях]] с низкой [[Доступность рынка|доступностью рынка]].
