# Табу

[[Религия]] может накладывать табу на определённые [[Товар|товары]]. [[Группа населения|Последователи]] данной религии будут тратить куда меньше денег на табуированные товары по сравнению с их аналогами из той же категории [[Потребности группы населения|востребованности]].
