# Авторитет

Авторитет — это [[Потенциал|потенциал]], который используется для проведения преобразований внутри [[Страна|страны]], например для издания [[Указ|указов]] или для управления [[Заинтересованная группа|заинтересованными группами]]. Вы получаете от принятых [[Закон|законов]].
