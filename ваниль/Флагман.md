# Флагман

Флагман — главный [[Корабль|корабль]] в военно-морском флоте [[Страна|страны]]. В каждый момент времени флагман может быть только один. Победы в сражениях с участием флагмана дают больше [[Престиж|престижа]] [[Страна|стране]], которой он принадлежит, тогда как поражения этот престиж подрывают.
