# Соперничество

[[Дипломатический пакт]], созданный одной [[Страна|страной]] против другой аналогичного [[Ранг|ранга]], который увеличивает [[Влияние|влияние]] [[Страна|страны]], объявившей соперничество. Для соперничества две страны должны иметь пересекающиеся [[Интерес|интересы]]. Этот пакт также ограничит допустимые [[Отношения|отношения]] между двумя странами на всё время, пока он остаётся в силе.
