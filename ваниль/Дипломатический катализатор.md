# Дипломатический катализатор

По сути, любое дипломатическое событие является дипломатическим катализатором, который может создать [[Политическое лобби|политические лобби]] или изменить [[Намерения|намерения]] [[Страна|страны]] по отношению к вам.

Катализатором может стать любое изменение на мировой арене, например:
- [[Дипломатическое действие|Дипломатические действия]]
- Действия в ходе [[Дипломатическая игра|дипломатических игр]]
- Изменение уровня [[Отношения|отношений]]
