# Преимущество во влиянии

Размер [[Влияние (power_bloc_leverage)|влияния]] [[Блок государств|блока государств]] на [[Страна|страну]] в сравнении с другими блоками. Если значение +положительное, у блока есть преимущество — то есть он обладает наибольшим влиянием. Если оно -отрицательное, этот блок отстаёт — то есть другой блок обладает большим влиянием, или [[Невостребованное влияние|невостребованное влияние]] страны выше.

Чтобы [[Лидер блока государств|лидер блока государств]] смог пригласить страну в блок, преимущество должно быть положительным и превышать пороговое значение.
