# Тело кредита

Общий размер [[Займы|займов]], взятых [[Казна|казной]], без учёта [[Проценты|процентов]]. Если [[Тело кредита|тело кредита]] превысит [[Кредит|кредит]], у вас произойдёт [[Дефолт|дефолт]].

### Как используется в форке

Тело кредита игры — сумма, которую модель раскладывает по держателям [[Облигации|облигаций]].
