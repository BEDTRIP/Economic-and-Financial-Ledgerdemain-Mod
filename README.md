# E&F: Ledgerdemain

Мод для Victoria 3 (1.13): форк **Economic and Financial Mod (E&F) - V4** со встроенным
**Private Sector Construction**. Ledger — бухгалтерская книга, legerdemain — ловкость рук:
деньги и металл не появляются из ничего, каждая операция сходится по счетам.

Состояние: работа идёт, мод ещё не опубликован.
