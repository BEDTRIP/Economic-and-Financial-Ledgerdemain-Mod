# Покрытие

**Что это.** Резервы ЦБ против денежной массы, **одним числом** (Д.R8а.5): резервы по рынку в металле стандарта / деньги.
Норма — 40 %; ниже 25 % [[Размен|размен]] приостановлен.

**Что входит в резервы:**

| стандарт | металл (оба, второй — по мировой цене месяца) | чужие валюты |
| --- | --- | --- |
| [[Металлический стандарт|металлический]] | да | **нет** — только свой металл |
| [[Обменный стандарт|обменный]] | да | да — валюты эмитентов, которые [[Размен|разменивают]] на металл |
| [[Внешневалютный стандарт|внешневалютный]], [[Фиат|фиат]] | да | да |

Чужая валюта оценивается по курсу эмитента **прошлого месяца** — две страны, держащие валюту друг друга, не зацикливают
расчёт; взаимное хранение раздувает покрытие обеим (так и было в 1920-х; обвал — кризисы R11).

**Что от него зависит:** [[Курс к паритету|ценность валюты]], ставка ЦБ металлического стандарта, кредит ЦБ, право быть
[[Эталонная валюта|эталоном]] (≥ 25 %), чужие держатели при [[Размен|размене]].
