# Банки

**Что это.** Банковский сектор страны: компании-банки (исторические банки E&F) + агрегаты «частные банкиры» (уровни
«Банка» у финцентров и усадеб, прибыль — [[Население|населению]]) и «государственные кассы» (уровни у государства,
прибыль — [[Казна|казне]]).

| баланс | что |
| --- | --- |
| активы | резервы (металл, банкноты и резервы ЦБ), кредиты (бизнес, население, другие страны), облигации, акции |
| пассивы | вклады (население, компании, казна, [[Вклады нерезидентов|нерезиденты]]), долг ЦБ; без ЦБ — свои банкноты |
| доход | маржа ставок + прибыль зданий «Банк» (расчёты) |

**Ёмкость банка** — уровни его зданий «Банк»: потолок вкладов и кредита. Доля банка в кредите = ёмкость ×
привлекательность ставки (без перебора пар); специализация — скидка к ставке для своего вида заёмщиков. Объём частного
кредита решает движок (стройка из [[Инвестиционный пул|пула]]), доля банка только раскладывает потраченное.

**Сейчас в коде:** один агрегат банков страны (книга банков, капитал); здания «Банк» (`building_zz_ef_bank`) производят
«банковские расчёты»; поштучные банки — R4; портфель банка — [[Словарь требований|словари требований]] (R8б → R4).
