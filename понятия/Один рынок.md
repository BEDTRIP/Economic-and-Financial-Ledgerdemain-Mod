# Один рынок

**Что это.** Рынок движка — общие цены и товары; деньги и счета — у каждой страны. Подданный и член таможенного союза
входят в чужой рынок, но их финансовая система остаётся (Россия взяла Персию в протекторат — персы вошли в рынок России,
их деньги остались).

**Сейчас:** сделки между странами одного рынка (продукция Баварии — потребителям Пруссии) модели не видны; член союза
считает торговлю по товарам своих штатов.

**Цель (R8в.1, решено 9.10 — вариант «доли рынка»):** позиция члена = (доля в производстве рынка − доля в потреблении) ×
оборот рынка; доли — двоичным поиском по триггерам `market_production_share` / `market_consumption_share` (проба ночью
9.10: читаются, < 1 с на 20 проходов). Зачёт внутри рынка, внешняя торговля рынка — по членам.
