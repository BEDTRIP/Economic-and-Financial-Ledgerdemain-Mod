# Фиат

**Что это.** Неразменные деньги: металла за ними нет, курс плавает. Норма [[Покрытие|покрытия]] не нужна — курс держат
инфляция и (с R8б) биржа; резервы — для защиты курса.

| свойство | как |
| --- | --- |
| [[Курс к паритету|курс]] | 1 на день перехода, дальше × (цены эталона / свои цены) с того дня |
| [[Ставка ЦБ]] | своя: нейтраль 2,5 % + инфляция; коридор 0,5–25 % |
| ценность валюты | 0,01 (E&F, не решалось) |
| технология | `currency_standards` |

**E&F, не решалось:** E&F переводит в фиат страну, изучившую `currency_standards` без денежной системы; на старте эту
технологию получают страны с подушным налогом с меткой `zz_ef_start_currency_standards`, чтобы не уйти в фиат.
