# Биржа

**Что это.** Одно место, где любой держатель меняет доступные ему виды [[Требование|требований]]; вместо форекса,
годовой чистки словарей и отдельных механизмов обмена. Каждая сделка платит [[Комиссия биржи|комиссию]].

**Где.** Одна на страну с [[Финцентр|финцентром]]. Нет своего — биржа хозяина рынка (если у него финцентр), иначе лидера
своего блока, иначе блока, сильнее всех влияющего на страну (`leverage_advantage`), иначе мировая (эталон).

**Как торгуют.** Дилерская биржа, не книга заявок: держатель торгует только с [[Фонд биржи|фондом своей биржи]]
(сведение каждой заявки с каждой — O(N²)). Торги — в день недельного шага держателя; заявка игрока — сразу. Решение —
[[Решение держателя]]. Связь бирж — [[Межрыночный субъект|межрыночные субъекты]] (арбитраж), запасной выход — мировая.

**Цена:** ~1 тыс. держателей × ~15 оценок в неделю ≈ 65 тыс. в месяц, без цепочек по валютам и перебора пар.

**Статус:** R8б. Исключительные события (потеря области, аннексия, революция, оккупация) — R11.
