# Биметаллизм

**Что это.** [[Металлический стандарт]] на двух металлах: единица денег по закону равна фиксированному количеству золота
**и** серебра. **Законное соотношение** золото : серебро — параметр стандарта (Д.R8а.11), не группа законов: его меняет
[[Денежная власть|денежная власть]] рядом со сменой паритета (рычаг в окне ставки ЦБ, ±0,5, 10…25). Стартовое — из
истории (Франция 15,5), иначе 15.

**Закон Грешема:** металл, завышенный законом против [[Цена серебра к золоту|мировой цены]], приходит, заниженный —
уходит. Паритет считается в золоте, покрытие — в золоте.

**Между странами** ([[Зачёт по группам металла]]): одинаковое соотношение — одна группа, как чистый металл (Латинский
союз закрепил 15,5 ради этого); разное — разница соотношений и есть цена пересчёта, металл перетекает.

Биметаллический [[Обменный стандарт|обменный]] держит соотношение так же; у [[Внешневалютный стандарт|внешневалютного]] на
биметаллическом якоре — соотношение якоря.
