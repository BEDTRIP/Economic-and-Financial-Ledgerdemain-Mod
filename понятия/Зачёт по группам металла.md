# Зачёт по группам металла

**Что это.** Порядок расчётов (пользователь 9.10, [[Клиринг]] R8в): сначала сальдо сводятся **внутри группы одного
металла** — золото, серебро, биметалл (обменные — в группе своего металла) — по [[Паритет|паритетам]], без курсового
риска и почти без комиссии; остаток группы — с другими группами через [[Биржа|биржу]] по
[[Цена серебра к золоту|мировой цене]] и с комиссией. [[Фиат]] — своя группа, зачёт по текущим курсам.

**Биметалл** делится по законному соотношению: одинаковое (Франция и Бельгия, 15,5) — одна группа, как чистый металл;
разное (Франция 15,5, США 16) — разница соотношений и есть цена пересчёта, плательщик платит металлом, переоценённым у
него по закону, металл перетекает (Грешем). Сменив соотношение, страна переходит в другую группу.

**Связи.** [[Решение держателя]] — требование на должника своей группы дешевле. Исторически страны одного металла
рассчитывались векселями по паритету, металл ездил только на остаток; [[Валютные союзы|Латинский союз]] — частный
случай.
