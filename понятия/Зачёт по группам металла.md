# Зачёт по группам металла

## Подсказка

Расчёты вашей [[Страна|страны]] с заграницей ([[Клиринг]]) сначала сводятся внутри группы стран одного
[[Металл|металла]] — золота, серебра или [[Биметаллизм|биметаллизма]]: такие страны гасят долги друг друга по
[[Паритет|паритетам]], почти без комиссии и без риска [[Курс к паритету|курса]]. Только остаток группы рассчитывается с
другими группами — через [[Биржа|биржу]], по [[Цена серебра к золоту|мировой цене серебра к золоту]] и с
[[Комиссия биржи|комиссией]]. [[Обменный стандарт]] входит в группу своего металла, а страны на [[Фиат|фиате]]
составляют свою группу и рассчитываются по текущим курсам.

[[Биметаллизм|Биметаллические]] [[Страна|страны]] с одинаковым законным соотношением [[Металл|металлов]] — одна группа.
При разном соотношении разница и есть цена пересчёта: плательщик платит металлом, который его [[Закон|закон]]
переоценивает, и металл перетекает. Сменив соотношение, страна переходит в другую группу. Поэтому долги стран своей
группы держать выгоднее ([[Решение держателя]]).

## Рабочее

### Целевое значение

Порядок расчётов (пользователь 9.10, Д.R8в.2): сначала сальдо сводятся **внутри группы одного металла** — золото,
серебро, биметалл (обменные — в группе своего металла) — по паритетам, без курсового риска и почти без комиссии; остаток
группы — с другими группами через биржу по мировой цене и с комиссией. Фиат — своя группа, зачёт по текущим курсам.

**Биметалл** делится по законному соотношению: одинаковое (Франция и Бельгия, 15,5) — одна группа, как чистый металл;
разное (Франция 15,5, США 16) — разница соотношений и есть цена пересчёта, плательщик платит металлом, переоценённым у
него по закону, металл перетекает (Грешем).

Стоимость выхода из требования на должника своей группы ниже (Д.R8б.15). Исторически страны одного металла
рассчитывались векселями по паритету, металл ездил только на остаток; [[Валютные союзы|Латинский союз]] — частный
случай.
