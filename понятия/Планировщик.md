# Планировщик

**Что это.** Одна глобальная цепочка, которая решает, кто и когда считает. Порядок шагов фиксирован: порядок
on_actions между файлами движок не гарантирует.

**Как устроен** (`docs/money-model.md`, «Поток / порядок»): цепочка на «якорной» стране (крупнейшей по ВВП на старте);
старт — на первом бюджетном тике после первой недели ([[Старт игры]]); каждый день — страны своего слота; **недельный
шаг** страны — в её день, **месячные шаги** — раз в календарный месяц со смещением; в конце недели — мировой проход
(мировые суммы, окно [[Клиринг|клиринга]]). Страны вне планировщика (роль В) — только хаб E&F.

**Связи.** [[Роли стран]] решают, кто в планировщике; [[Мост GUI]] только приносит числа; торги [[Биржа|биржи]] — в день
недельного шага держателя.

**В коде:** `zz_ef_sched_*`, `common/on_actions/ld_scheduler_on_actions.txt`.
