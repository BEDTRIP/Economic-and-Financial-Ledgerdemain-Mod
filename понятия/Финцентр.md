# Финцентр

## Подсказка

Финансовый центр — [[Сооружение|здание]] [[Биржа|биржи]] вашей [[Страна|страны]], одно на страну. Его учреждает [[Запись в дневнике|запись в дневнике]] «Учреждение биржи», доступная экономически значимым странам ([[Категория А]]) с [[Технология|технологией]] финансового центра, своей [[Денежный стандарт|денежной системой]] и развитыми [[Банки|банками]] — не меньше 5 уровней банков в стране. Биржи, существовавшие в 1836 году, остаются у своих стран. Из меню [[Строительство|строительства]] его не построить — только расширить; уровни финансового центра — места для выхода [[Компания|компаний]] на биржу.

Вид центра — только оформление: название, иконка и [[Область|область]], где он появляется (по умолчанию — [[Столица государства|столица]], у США — Нью-Йорк).

## Рабочее

### Целевое значение

**Одно на страну** (у Британии — только Лондон; Д.R8.7). Учреждается записью дневника «Учреждение биржи» (основа — E&F
`financial_center_je_1`, для всех стран, без подарка технологий): технология `financial_center`, категория А, своя
денежная система (стандарт — не «без системы») и банковский сектор не меньше порога (Д.R8б.1). Биржи из истории у стран
вне категории А остаются (Д.R8б.14). Из меню стройки не строится, только расширяется; уровни — места для листинга
компаний (R6). Доход владельцев — [[Комиссия биржи|комиссия]]; уровни у населения —
[[Частная собственность|частный сектор]].

**Варианты — только оформление:** название, иконка, область появления; в коде финцентр один (группа
`bg_financial_centre`), типы — генератором из таблицы. Вторые биржи (Манчестер, Чикаго, Гонконг) — в архив. **Блок
государств** — только со своим финцентром; Османам — биржа в Константинополе с истории.

### Что в коде

Сделано (R8б, шаг 4): типы — генератор `regen_ld_financial_centres.py` (общий + 38 вариантов, таблица «вариант → тег,
область, иконка»; Манчестер, Чикаго, Гонконг — в архиве); биржа страны — `var:zz_ef_fc_state` (финцентр истории на
старте — `zz_ef_fc_bind`; новая — запись «Учреждение биржи», `zz_ef_fc_found`), расширяется только она
(`zz_ef_fc_possible`); проверки — по группе `bg_financial_centre`; самосоздание E&F — в архиве; Османам — Восточная
Фракия с 1836; блок государств — только со своей биржей (`country_can_form_power_bloc`). Порог банков — 5 уровней
(Д.R8б.24). Значки вариантов в окне ЦБ — по скриптовым окнам E&F (R10). Паи (`mutual_funds`) выпускает метод финцентра
`pm_bond_exchange` — переходят к зданию [[Инвестиционный фонд|инвестиционного фонда]] (R8б, шаг 6);
`docs/exchange-companies.md`.
