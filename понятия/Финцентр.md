# Финцентр

**Что это.** Здание [[Биржа|биржи]] страны, **одно на страну** (у Британии — только Лондон). Учреждается **записью
дневника** «Учреждение биржи» (основа — E&F `financial_center_je_1`, для всех стран, без подарка технологий):
технология `financial_center`, [[Категория А]], остальные условия — до кода R8б. Из меню стройки не строится, только
расширяется; уровни — места для листинга [[Компания|компаний]].

**Варианты — только оформление:** название, иконка, область появления (США — Нью-Йорк; по умолчанию — столица); в коде
финцентр один (группа `bg_financial_centre`), типы — генератором из таблицы. Вторые биржи (Манчестер, Чикаго, Гонконг) —
в архив. **Силовой блок** — только со своим финцентром; Османам — биржа в Константинополе с истории.

**Сейчас в коде:** 42 вида финцентров E&F; дневник — только у игрока, дарит технологии по ВВП; `docs/exchange-companies.md`.
