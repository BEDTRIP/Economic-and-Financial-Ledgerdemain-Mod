# Финцентр

## Подсказка

Финансовый центр — [[Сооружение|здание]] [[Биржа|биржи]] вашей [[Страна|страны]], одно на страну. Его учреждает
[[Запись в дневнике|запись в дневнике]] «Учреждение биржи», доступная экономически значимым странам ([[Категория А]]) с
[[Технология|технологией]] финансового центра. Из меню [[Строительство|строительства]] его не построить — только
расширить; уровни финансового центра — места для выхода [[Компания|компаний]] на биржу.

Вид центра — только оформление: название, иконка и [[Область|область]], где он появляется (по умолчанию —
[[Столица государства|столица]], у США — Нью-Йорк).

## Рабочее

### Целевое значение

**Одно на страну** (у Британии — только Лондон; Д.R8.7). Учреждается записью дневника «Учреждение биржи» (основа — E&F
`financial_center_je_1`, для всех стран, без подарка технологий): технология `financial_center`, категория А, остальные
условия — до кода R8б. Из меню стройки не строится, только расширяется; уровни — места для листинга компаний (R6). Доход
владельцев — [[Комиссия биржи|комиссия]]; уровни у населения — [[Частная собственность|частный сектор]].

**Варианты — только оформление:** название, иконка, область появления; в коде финцентр один (группа
`bg_financial_centre`), типы — генератором из таблицы. Вторые биржи (Манчестер, Чикаго, Гонконг) — в архив. **Блок
государств** — только со своим финцентром; Османам — биржа в Константинополе с истории.

### Что в коде

42 вида финцентров E&F; дневник — только у игрока, дарит технологии по ВВП; `docs/exchange-companies.md`.
