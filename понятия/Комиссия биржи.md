# Комиссия биржи

**Что это.** Главная ручка [[Биржа|биржи]] (Д.R8.5): своя по видам актива (база — 0,5 %), чтобы субъекты не гоняли мелочь
по кругу. Доход — владельцам [[Финцентр|финцентра]] по долям (компании, «частный сектор» → население, государство →
казна). Технологии её снижают. **Управление биржей** — у государства: уровень комиссии и запреты ввоза / вывоза
капитала (игрок — кнопки, ИИ — по весам). Числа — R11.
