# Комиссия биржи

## Подсказка

Каждая сделка на [[Биржа|бирже]] платит комиссию — свою для каждого вида актива, обычно около половины процента. Она не
даёт гонять мелкие суммы туда и обратно, а её доход получают владельцы [[Финцентр|финансового центра]]:
[[Компания|компании]], [[Группа населения|население]] через [[Частная собственность|частные]] уровни и [[Казна|казна]]
через [[Собственность государства|государственные]]. [[Технология|Технологии]] снижают комиссию.

Правительство вашей [[Страна|страны]] управляет [[Биржа|биржей]]: устанавливает уровень комиссии и может запретить ввоз
или вывоз капитала.

## Рабочее

### Целевое значение

Главная ручка биржи (Д.R8.5): своя по видам актива (база — 0,5 %), чтобы субъекты не гоняли мелочь по кругу. Доход —
владельцам финцентра по долям (компании, [[Частная собственность|«частный сектор»]] → население, государство → казна).
Технологии её снижают. **Управление биржей** — у государства: уровень комиссии и запреты ввоза / вывоза капитала (игрок
— кнопки, ИИ — по весам). Курс металлических стандартов ходит вокруг паритета в пределах комиссии ([[Курс к паритету]]).
Числа — R11.
