# Витрина

**Что это.** Готовые числа для окон (`zz_ef_v_*`): окна читают только их и ничего не считают сами. Каждый этап держит
витрину живой, поэтому интерфейс не ломается между этапами. Витрина — **только у играющих игроков**: у ИИ те же счета
и та же логика, без таблиц и подсказок ([[Принципы мода|принцип 7]]).

**Открыто:** 419 из 592 имён витрины считаются при перерисовке — перенести в переменные шага (R10).
