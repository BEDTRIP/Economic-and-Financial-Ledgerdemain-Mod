# Витрина

## Подсказка

Витрина — готовые числа для окон финансовой системы: окна только показывают их и ничего не считают сами, поэтому на экране — ровно то, что посчитано. Витрину ведут только для [[Страна|стран]], за которые играют люди; у стран ИИ те же счета и те же решения, только без таблиц и подсказок.

## Рабочее

### Целевое значение

Слой «витрины» с R1а (Д.R0.8.10): окна читают только её; каждый этап держит витрину живой, поэтому интерфейс не ломается
между этапами. Витрина — **только у играющих игроков** (Д.R3б.3, [[Принципы мода|принцип 7]]).

**Открыто:** большая часть имён витрины (416 из 586, `ld_vitrine.py`) считается при перерисовке — перенести в переменные
шага (R10).
