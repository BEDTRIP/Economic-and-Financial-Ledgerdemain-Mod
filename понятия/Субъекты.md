# Субъекты

Экономика — система субъектов: каждый принимает выгодные для себя решения, порядок и кризисы возникают из их
взаимодействия, а не из ручных правил («детерминированный хаос», пользователь 7.10). Считается в оптимизированном
виде — по [[Роли стран|ролям]] и агрегатами.

| субъект | цель | активы | пассивы |
| --- | --- | --- | --- |
| [[Казна]] | политика страны | деньги своей страны, облигации (свои и чужие) | облигации и кредиты |
| [[Центральный банк]] (опционален) | курс, цены, кредит | металл, чужая валюта, облигации, кредиты | банкноты, резервы банков, счёт казны |
| [[Население]] (агрегат на страну) | уровень жизни | наличные, вклады, металл, акции, облигации | потребкредит |
| [[Банки]] (компании + агрегаты) | доходность | кредиты, резервы, облигации, акции | вклады, долг ЦБ |
| [[Компании]] | прибыль | здания, только деньги | кредиты банков |
| [[Фонд биржи]] | спред | требования любых видов, металл | паи населения и банков |

Без ЦБ — [[Свободные банки]]. Банкротство — у любого, кроме населения: [[Банкротство]]. Здания движка между
субъектами передаются пересозданием (проба 7.10: рабочие уволены, касса новая, ~1 месяц выпуска) — для редких событий.

**Сейчас в коде:** счета страны и населения, агрегат банков, металл ЦБ / банков / населения ([[Проводка]]); поштучные
банки, компании, фонды — этапы R4, R6, R8б.
