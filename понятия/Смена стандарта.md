# Смена стандарта

**Что это.** Переход на другой закон [[Денежный стандарт|стандарта]] сохраняет ценность денег в золоте: запасы ЦБ и
[[Паритет|паритет]] пересчитываются по [[Цена серебра к золоту|цене серебра к золоту]].

| переход (по металлу) | запасы ЦБ | паритет |
| --- | --- | --- |
| серебро → золото | серебро в золото | × s2g |
| серебро → биметалл | как есть | × s2g |
| биметалл → золото | серебро в золото | как есть |
| золото / биметалл → серебро | золото в серебро | / s2g |
| золото → биметалл, тот же металл | как есть | как есть |

Обменный стандарт считается по металлу своего закона. На фиат и «без системы», и стандарт, взятый без паритета, — как
у E&F. Каждая смена закона даёт 12 месяцев валютного контроля и переходного периода (E&F).

**В коде:** `ld_standard_switch.txt` (`zz_ef_std_switch_before/_after` внутри E&F `on_activate_monetary_system_law`); лог
`EFM|…|std_switch`.
