# Что из E&F

Форк — E&F 4.1.7 со встроенным PSC; ядро E&F (95 валют лестницами, нацзапас, фонды частных банков, копии ванильных окон)
живёт рядом с нашей моделью `ld_*`. Правило: механизм E&F либо встроен в учёт ([[Проводка]]), либо уходит в `_archive/`;
унаследованное без решения помечается в заметках «E&F, не решалось» — это кандидат на вопрос пользователю.

| механизм E&F | решение |
| --- | --- |
| 95 валют (названия, символы, законы `law_<cur>_currency`) | данные страны ([[Валюта страны]]); законы — в архив (R8в) |
| стандарты, институт ЦБ, методы стандартов | оставить, поведение — наше ([[Денежный стандарт]]) |
| здание ЦБ `building_bank` | в архив в R4; металл ЦБ — его «Банки» |
| финцентры (42 вида), биржи, методы акций и облигаций | один финцентр с вариантами ([[Финцентр]]) |
| 105 компаний-банков | компании ([[Банки]]); пять Ротшильдов — один [[Межрыночный субъект]] |
| финтовары: `bond`, акции, `mutual_funds`, «банковские расчёты» | оставить; `local_currency` — убран |
| нацзапас | в архив ([[Нацзапас]]) |
| ИИ-форекс, арбитражи, `investement_pool_borrowing` | в архив (R2); форекс — [[Биржа]] |
| покупка облигаций `ai_buy_bond_*`, `bond_maturity_*` | слоты → словари (R8б), заявки на бирже (R5) |
| инфляция E&F, колебания курсов | наш индекс цен и [[Курс к паритету]] |
| окна E&F и копии ванильных окон | нужное игроку — пересобрать на модели (R10), остальное — в архив |
| события и журналы E&F (валютные союзы, финцентр, ЦБ) | переподключить к модели |
| банкротство ЦБ и валютный кризис E&F (`is_extreme_weak_currency`, спад ценности > 50 % за полгода) | **E&F, не решалось** — по шкале E&F, не модели; R4 |
| автопереход ИИ между стандартами (`is_monetary_systeme_transition_valid_*`, теги) | **E&F, не решалось** — R11 |

Реестр механизмов (живой / выключен / мёртвый / дубль) — `docs/mechanisms.md`.
