# Банкротство

**Что это.** Есть у любого субъекта, кроме населения: активы — кредиторам **пропорционально**, остаток — владельцам.

- **Банк:** капитал < 0 или нет ликвидности при бегстве вкладов, и ЦБ не спас — кредиты продаются другим банкам со
  скидкой, выручка и резервы — кредиторам, здания «Банк» — пересозданием, компания расформирована (страна может
  создать заново). Потери населения — по потреблению расчётов и акций.
- **ЦБ:** нехватка металла при металлическом стандарте — приостановка [[Размен|размена]], а не банкротство; капитал < 0
  — государственный докапитализирует казна или девальвация, частный — банкротство как у банка.
- **Компания:** капитал < 0 или N месяцев нет денег на проценты — здания продаются пересозданием.
- **Страна:** дефолт движка — списание держателям облигаций пропорционально.
- **Фонд биржи** — паника (R11).

Очередь банкротств, разбор раз в месяц, не больше N за проход; у роли Б — частичное банкротство агрегата.

**Статус:** R4 (банки, ЦБ), R6 (компании), R11 (фонды, кризисы). Банкротство ЦБ E&F — см. [[Центральный банк]].
