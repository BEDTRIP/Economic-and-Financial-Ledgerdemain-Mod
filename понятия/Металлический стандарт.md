# Металлический стандарт

**Что это.** Деньги обеспечены своим металлом: ЦБ [[Размен|разменивает]] банкноты на металл стандарта по
[[Паритет|паритету]]. Три закона — золотой, серебряный, [[Биметаллизм|биметаллизм]].

| свойство | как |
| --- | --- |
| [[Покрытие]] | **только свой металл** (оба металла; второй — по мировой цене); чужие валюты в резервах лежат, но покрытие не увеличивают |
| ценность валюты | паритет с поправкой на покрытие |
| [[Ставка ЦБ]] | своя: нейтраль 3 % + рост денег − ВВП + покрытие; коридор 2–12 % |
| технология | `metalique_standard` |
| переходы | серебряный — отовсюду; биметаллизм — с серебра, золота, любого обменного; золото — с биметалла и любого обменного |
| запреты | не при изоляционизме и не в денежном кризисе |

Апгрейд — [[Обменный стандарт]] того же металла.
