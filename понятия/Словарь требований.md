# Словарь требований

**Что это.** Хранилище [[Требование|требований]] держателя: «должник → сумма» на каждый вид, без слотов и без предела —
карта переменных движка (`add_to_variable_map`). Актуальность — не список и не порог: ненужное держатель продаёт
[[Фонд биржи|фонду биржи]], нужное покупает; годовой чистки нет.

**Проба (ночь 9.10, `_archive/ld_probe_map/` форка):** значения — число, скрипт-значение или скоуп; чтение
`"variable_map(X|ключ)"` (в кавычках); повторная запись по ключу значение не меняет (удалить и записать); перебор ≈
`every_country` (~3,5 мкс на чтение); переживает сейв.

**Статус:** R8б, шаги 1–2.
