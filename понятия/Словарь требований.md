# Словарь требований

## Подсказка

Словарь требований — портфель держателя: кто ему сколько должен по каждому виду [[Требование|требований]] — чужим деньгам, [[Облигации|облигациям]], акциям, кредитам. Любое требование из портфеля можно продать на [[Биржа|бирже]] ([[Решение держателя]]). Позиции меньше 1 % портфеля держатель отдаёт [[Инвестиционный фонд|инвестиционному фонду]] со скидкой, поэтому в портфеле остаются только заметные должники.

## Рабочее

### Целевое значение

Хранилище требований держателя: «должник → сумма» на каждый вид, без слотов (Д.R8.8). Актуальность — не список и не
годовая чистка: ненужное продаётся на бирже, нужное покупается ([[Принципы мода|принцип 12]]). **Предел** (Д.R8б.22):
позиция меньше 1 % портфеля держателя выставляется по нижней цене и продаётся первой; что никому не нужно, выкупает фонд
(Д.R8б.32, Д.R8б.36) — словари не разрастаются ([[Скорость]]).

### Что в коде

Частично (R8б, шаги 1–2). Реестр — `docs/claims.md`: карты переменных игры на держателе (`zz_ef_rq_<держатель>_<вид>`,
ключ — страна-должник), итог вида у должника (`zz_ef_rq_out_<вид>`), сверка раз в месяц (лог `EFI`). Сделано: чужие
деньги ЦБ (клиринг, проценты, кризис); облигации казны и банков — шаг 2; банки и население — шаг 7 (биржа). Проба
(`_archive/ld_probe_map/`): повторная запись по ключу значение не меняет (удалить и записать); перебор ≈
`every_country`; переживает сейв.
