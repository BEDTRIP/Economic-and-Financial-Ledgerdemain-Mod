# Словарь требований

## Подсказка

Словарь требований — портфель держателя: кто ему сколько должен по каждому виду [[Требование|требований]] — чужим деньгам, [[Облигации|облигациям]], акциям, кредитам. Должников в портфеле может быть сколько угодно; ненужное держатель продаёт [[Инвестиционный фонд|инвестиционному фонду]], нужное покупает ([[Решение держателя]]).

## Рабочее

### Целевое значение

Хранилище требований держателя: «должник → сумма» на каждый вид, без слотов и без предела (Д.R8.8). Актуальность — не
список и не порог: ненужное продаётся фонду, нужное покупается; годовой чистки нет ([[Принципы мода|принцип 12]]).

### Что в коде

Частично (R8б, шаги 1–2). Реестр — `docs/claims.md`: карты переменных игры на держателе (`zz_ef_rq_<держатель>_<вид>`,
ключ — страна-должник), итог вида у должника (`zz_ef_rq_out_<вид>`), сверка раз в месяц (лог `EFI`). Сделано: чужие
деньги ЦБ (клиринг, проценты, кризис); облигации казны и банков — шаг 2; банки и население — шаг 7 (биржа). Проба
(`_archive/ld_probe_map/`): повторная запись по ключу значение не меняет (удалить и записать); перебор ≈ `every_country`;
переживает сейв.
