# Словарь требований

## Подсказка

Словарь требований — портфель держателя: кто ему сколько должен по каждому виду [[Требование|требований]] — чужим
деньгам, [[Облигации|облигациям]], акциям, кредитам. Должников в портфеле может быть сколько угодно; ненужное держатель
продаёт [[Инвестиционный фонд|инвестиционному фонду]], нужное покупает ([[Решение держателя]]).

## Рабочее

### Целевое значение

Хранилище требований держателя: «должник → сумма» на каждый вид, без слотов и без предела (Д.R8.8). Актуальность — не
список и не порог: ненужное продаётся фонду, нужное покупается; годовой чистки нет ([[Принципы мода|принцип 12]]).

### Что в коде

Нет; R8б, шаги 1–2. Хранилище — карта переменных игры (`add_to_variable_map`). Проба (`_archive/ld_probe_map/`):
значения — число, скрипт-значение или скоуп; чтение `"variable_map(X|ключ)"` (в кавычках); повторная запись по ключу
значение не меняет (удалить и записать); перебор ≈ `every_country` (~3,5 мкс на чтение); переживает сейв.
