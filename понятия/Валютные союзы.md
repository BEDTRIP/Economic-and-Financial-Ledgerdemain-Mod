# Валютные союзы

**Что это.** Исключение из «у каждого тега своя валюта» ([[Валюта страны]]). Латинский (1865) — у каждой страны своя
монета одного веса и соотношения 15,5 ([[Биметаллизм]]); Скандинавский — другое устройство. Статус — R8в.
