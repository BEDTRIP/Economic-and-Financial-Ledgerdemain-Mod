# Проба R4б.1 (Р26): где жить субъекту-банку

**Что делало:** само, на месячном пульсе каждой страны (событие `ld_probe_bk.1` — своя строка профилировщика): (а)
переменная и карта на 30 ключей на компании и в контейнере (`create_container`, родитель — компания), чтение из страны
(сумма в переменную страны) и из окна (окно читает `Company.MakeScope.Var` и возвращает мостом); (б) уровни «Банка»
компании — окно передаёт скрипту (у скрипта триггера нет); (в) нагрузка карт: каждая компания страны с «Банками» и два
субъекта на страну — 4 круга чтение / удаление / запись по 30 ключам (как запись реестра требований). Лог
`EFZ|…|bk_probe|`, `bk_comp|`.

**Итог (прогоны r1012_100056, r1012_101806, r1012_103016 + продолжение r1012_103436, r1012_103932; 1.13):**
- Область компании держит переменные и карты; окно их читает (`Company.MakeScope.Var(...)` — то же значение с
  отставанием на шаг моста); страна читает переменную компании (`prev.var:…` из `every_company`).
- Контейнер (`create_container = { parent = <компания | страна> tags = { … } save_scope_as = … }`) держит переменные и
  карты; ссылка на него — переменная (`set_variable = { name = x value = scope:… }`, затем `var:x = { … }`);
  контейнеры и переменные компаний **переживают сейв и загрузку** (счётчики продолжились после загрузки 1.1.1837).
- Уровни здания одного типа у компании скрипт не видит: `company_owned_levels` — все её уровни, а банковские компании
  по истории E&F владеют и торговыми центрами, стройсектором, рудниками (сейв 1845: 92 уровня торговых центров, 47
  стройсектора у владельцев «Банков», `tools/ld_save_banks.py`). Окно видит:
  `GetBuildingType('building_zz_ef_bank').GetNumLevelsOwnedByCompanyRaw( Company.Self )` (так читает ванильная панель
  компаний) и `Company.GetBuildingTypeLevels( GetBuildingType('…').Self )` — совпадают; без `.Self` — nullptr.
- **`IntToFixedPoint` даёт float, `MakeScopeValue` его не берёт** (nullptr в `error.log`); int32 → число —
  двоичным разложением: сумма `Select_CFixedPoint( IsOdd_int32( Divide_int32( L, 2^k ) ), 2^k, 0 )`.
- Литерал `'(CFixedPoint)5'` и `MakeScopeFlag` с компанией в корне моста проходят; эффект удаления из глобального
  списка — `remove_list_global_variable`.
- Сколько субъектов (сейвы, `ld_save_banks.py`): компаний с уровнями «Банка» — 30 (1837), 32 (1840), 31 (1845) на 24–36
  стран с банками; плюс два агрегата на страну с банками — не больше ~100 субъектов.
- Цена (профилировщик, r1012_101806, захват 482,9 с, 27 месяцев): весь месячный хук с пробой — 3,8 с (≈ 0,14 с / мес)
  при нагрузке на все компании стран с «Банками» (их больше, чем банковских); без нагрузки на компании (r1012_100056) —
  0,10 с / мес; отдельной строкой проба в листьях не видна (< 0,5 с). Порог 1 с / мес не достигнут — портфели требований
  по банкам (Д.R4б.2).
- Ошибок по файлам пробы, кроме разобранных выше, нет.
