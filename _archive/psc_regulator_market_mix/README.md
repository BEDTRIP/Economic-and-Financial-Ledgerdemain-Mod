# Закупка регулятора стройки по рынку (`psc_regulator_market_mix`)

Вынуто 14.10.2026 (R9, шаг 4 — Д.R9.5, была Д.R8в.24) и снова 15.10.2026 (R9б.2 — Д.R9.11). Механизм работал, но
результат хуже — по правилу ночи откат. Здесь — вариант R9б.2 (очки по базовой цене товара метода, без базовой цены смеси).

**Что делал:** каждый метод регулятора брал по 10 единиц каждого из четырёх стройтоваров на очко, доли резали
модификаторы `zz_ef_reg_in_<товар>` (`goods_input_<стройтовар>_mult` — свои типы, у товаров мода их нет); доля товара
`var:zz_ef_reg_s_<товар>` штата — полшага в неделю к предложению рынка × (самая низкая местная цена / цена)²; базовая
цена смеси `var:zz_ef_reg_bp` — для модели цены PSC и веса штата; множители входа — локальные переменные штата
(`zz_ef_reg_market_step` в цикле штатов `set_construction_point_demand`, перед `state_construction_base_price`).

**Почему снят:** прогон всех шагов R9 со смесью r1014_193852 против того же кода без неё r1014_195947 (до 1841): очки
мира 1839 / 1840 / 1841 — 1023 / 1119 / 1163 против 1345 / 1423 / 1448 (−21 %), выпуск секторов (сейв 1841) 8,8 против
11,3 тыс., доля недель без трат у стран с секторами ~70 % против ~48 %; лучше — `gap_psc` −15,0 против −24,0 млн, железо
продажи / заказы 0,78 против 0,59, казна 75 против 54 млн. Очки идут по базовой цене смеси: дерево (база 130) дороже
железа (92), и переход на избыточное дерево дорожает в модели PSC. Вопрос — В.R9.11 (`docs/история/2026-10-14 этап R9.md`,
«Вопросы на утро»); решено — вернуть без базовой цены смеси, очки по базовой цене товара метода сектора (Д.R9.11, R9б).

**Вторая попытка (R9б.2, `a774e3d`, откат 15.10):** без базовой цены смеси — очки и вес штата по базовой цене товара
метода регулятора. Прогон r1015_001851 против прогона шага R9б.1 r1014_233558 (до 1841): очки мира 1837–1841 — 822 /
1013 / 1087 / 1171 / 1190 против 967 / 1093 / 1256 / 1358 / 1417 в неделю (−7…−16 %), доля недель без трат у стран с
секторами 68–73 % против 45–58 %; лучше — `gap_psc` −0,65…−0,98 против −1,0…−1,9 млн в месяц. Смесь переводит заказы
регуляторов на дешёвое дерево — и дерево уходит в нехватку: продажи / заказы 0,85 (было 1,23 в избытке), железо 0,78.
Очки падают не от базовой цены, а от нехватки обоих товаров. Вопрос — В.R9б.5 (`docs/история/2026-10-17 этап R9б.md`, «Вопросы на утро»).
