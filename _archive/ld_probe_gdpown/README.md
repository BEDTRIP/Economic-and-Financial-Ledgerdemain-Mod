# Проба R8б, шаг 0: доли ВВП у чужих владельцев (`gdp_ownership_ratio`)

**Что делало:** `ld_probe_gdpown.1` (только из консоли) — для каждой пары стран «хозяин — владелец» лестница
`gdp_ownership_ratio = { target = <владелец> value > 0.01 / 0.05 / 0.10 / 0.25 / 0.50 }` (скоуп — хозяин), строка `EFZ` для
доли выше 1 %; цена двойного перебора всех стран.

**Итог (прогон r1009_044100, старт 1836):** 27 пар с долей выше 1 % — владельцы: Великобритания (до > 50 %),
Ост-Индская компания (> 25 %), Австрия (> 10 %), Пруссия (> 50 %), Испания (> 25 %), Нидерланды, Россия, Сёгунат,
Боливия, Венгрия. Двойной перебор всех стран с лестницей — меньше секунды. Имя хозяина через `SCOPE.sCountry('…')` в
`debug_log` не выводится (пусто).

**По документации (`script_docs` 1.13):** у здания — `levels_owned_by_country = { target = c:X value >= 1 }`,
`fraction_of_levels_owned_by_country`, `country_ownership_fraction`; у компании — `company_owned_levels`,
`company_employed_levels`; перебора зданий компании нет (`every_scope_building` — только страна и штат).

**Вырезано:** `events/ld_probe_gdpown_events.txt` (здесь), строка `EFZ` таблицы логов `docs/entry-points.md`.
