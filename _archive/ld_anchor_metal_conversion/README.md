# Пересчёт резервов подданного в металл якоря

**Что делал.** `zz_ef_anchor_metal_step` (из `zz_ef_anchor_update`, `ld_anchor.txt`): у подданного на внешневалютном
стандарте переписывал резервы ЦБ в металл якоря по курсу (серебро → золото по `silver_to_gold_rate` и наоборот).

**Почему вынуто.** Д.R8в.28: металл не превращается в другой — ЦБ держит оба, покрытие считает их по мировой цене
(`zz_ef_reserves_in_gold`). Пересчёт давал серебро из ниоткуда и золото в никуда в мировой линии металла (EFV, прогон
r1011_204954: Ост-Индская компания 26.5.1836).

**Удалено из живых файлов:** определение `zz_ef_anchor_metal_step` (здесь) и его вызов `zz_ef_anchor_metal_step = yes` в
`zz_ef_anchor_update` (`common/scripted_effects/ld_anchor.txt`).
