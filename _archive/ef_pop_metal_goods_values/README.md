# Значения `zz_ef_pop_gold_goods` / `zz_ef_pop_silver_goods` (мёртвые после оптимизации)

**Что делали:** покупка золота / серебра населением за неделю = потребление металла штатами (`zz_ef_state_*_cons`) минус
вход ЦБ и банков (`zz_ef_cb_in_*_goods`, `zz_ef_bank_in_*_goods`). Читал их `zz_ef_metal_week_step`.

**Почему вынесены:** ФК2 шаг 5 (оптимизация, 7.10): шаг считает вход ЦБ и банков один раз во временные
`zz_ef_t_cb_in_*` / `zz_ef_t_bank_in_*` и собирает покупку населения той же формулой прямо в
`common/scripted_effects/ld_metal_accounts.txt`; на значения ссылок не осталось.

**Удалено из живых файлов:** только определения (вызовы заменены в коммите оптимизации). **Вернуть:** не нужно —
формула та же в `zz_ef_metal_week_step`.
