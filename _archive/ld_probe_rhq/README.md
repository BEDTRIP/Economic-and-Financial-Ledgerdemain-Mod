# Проба R9а.1: присутствие компании в чужой стране

**Что делало:** `ld_probe_rhq.1` (только из консоли, любая страна) ставит в Париже «Банк» (`building_zz_ef_bank`) на 3
уровня во владении компании `company_Rothschild_Bank_gbr` (Британия), пишет `EFP|…|rhq|…`: пороги
`levels_owned_by_country` и `fraction_of_levels_owned_by_country` по Британии и Франции; затем ставит там же
региональный штаб компании (`create_building` здания `building_company_regional_headquarter`) и проверяет, видит ли его
компания (`any_scope_regional_hqs`).

**Итог (прогон r1016_203107, 9.1841):**
- `levels_owned_by_country` (скоуп — здание) считает уровни компании уровнями её страны: «Банк» Ротшильдов в Париже —
  уровни Британии ✓. На этом стоят местные книги (R9а.4).
- `create_building` регионального штаба ставит здание в штате, но `any_scope_regional_hqs` компании его не видит:
  присутствие региональным штабом скриптом не сделать → Д.R9а.8 (присутствие — уровни «Банка», требование DLC Charters
  of Commerce снято).
- В истории ванили региональных штабов нет; компании владеют уровнями в чужих странах и без них.
- Ошибок по файлу пробы нет.
