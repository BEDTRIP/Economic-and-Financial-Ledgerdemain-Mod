# Проба R8в.4: валютный союз

**Что делало:** `ld_mu_probe.0` (только из консоли) через 45 дней (ЦБ старта уже стоят) вводит Бельгию, Швейцарию и
Сардинию в союз Франции, как это сделали бы их договоры (`zz_ef_mu_join`; Сардиния — через Бельгию); через 120 дней
Франция берёт золотой стандарт (члены должны пойти за ней); ещё через 120 дней договор Швейцарии разрывается
(`zz_ef_mu_split`, она уходит одна). Лог — `EFM|…|mu_*`, `EFZ|…|mu_probe`.

**Итог (прогоны r1010_201310, r1010_202626, r1010_203619, r1011_063221, старт 1836):**
- Вступление, смена стандарта главы и разрыв работают: члены идут за паритетом и стандартом главы (`mu_sync`),
  Швейцария выходит со своей валютой по паритету союза (`mu_leave`, 13.10.1836).
- ИИ сам основывает союзы статьёй договора: Австрия и Обе Сицилии (октябрь 1836), Пруссия и Швеция (1836).
- Глава — Франция (престиж 422 против 23–62 у членов), у союза Пруссии — Пруссия; найденная ошибка — `ordered_country`
  без `max` выполнял тело для всех кандидатов, главой оставался последний (наименьший престиж); исправлено `max = 1`.
- Ошибок по файлам форка нет.
