# Символ валюты в верхней панели — 96 текстбоксов

**Что делало.** Тип `currency_symbol_top_bar` (`gui/00_ef_deported_gui_2.gui`, вызов — `gui/topbar.gui`) держал
текстбокс на каждый из 95 законов валюты (`currency_symbol_<cur>`, у каждого свой сдвиг и размер под глиф) и общий
(`currency_symbol_generic`, размер 45); показывался тот, чья custom-локализация не пуста. Каждая перерисовка верхней
панели считала все 96.

**Сейчас (R3б.9 (в), Д.R3б.3):** один текстбокс `[Country.GetCustom('currency_symbol')]` (валюта `var:zz_ef_cur` или
общий символ), сдвиг { 0 -2 }, размер 25 — подгонка под глиф и формат знака — R10 (Д.R8а.8).

**Вырезано:** тело типа целиком — `gui/00_ef_deported_gui_2.gui` (здесь). Custom-локализация `currency_symbol_<cur>` и
`currency_symbol_generic` остались (пишет `regen_ld_currency_data`); символы валют по тегу — R8а.

**Вернуть:** заменить тип на вырезанный.
