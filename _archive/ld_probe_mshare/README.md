# Проба R8в.1: доли членов рынка в производстве и потреблении

**Что делало:** `ld_probe_mshare.1` (только из консоли) — у каждого члена рынков GBR, RUS, TUR, AUS доля в производстве и
потреблении рынка лестницей из 20 сравнений по 5 % (`market_production_share` / `market_consumption_share = { target =
<страна> value > x }`, скоуп — рынок; члены — `every_country = { limit = { market = scope:<рынок> } }`), сумма по
рынку; `.2` — 20 проходов двух лестниц по всем странам (цена). Вывод — `EFZ` в `debug.log`.

**Итог (прогон r1009_041102, старт 1836):**
- Доли читаются: рынок GBR — две страны 0,40 / 0,45 и 0,35 / 0,30 (произв. / потр.), ещё ~60 членов ниже 5 %; RUS —
  0,95 / 0,95; TUR — 0,80 / 0,75 и 0,05 / 0,10; AUS — 0,65 / 0,80 и 0,15 / 0,10.
- Сумма с шагом 5 % (округление вниз) — 0,75…0,95: мелкие члены теряются; точнее — двоичным поиском (7 сравнений на
  долю до 1 %).
- Цена: 20 проходов × все страны × 40 сравнений — меньше секунды (метки `debug.log` в одну секунду).
- Имя члена через `SCOPE.sCountry('…')` в `debug_log` не вывелось (пусто).
