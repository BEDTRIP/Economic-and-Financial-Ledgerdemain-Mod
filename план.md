## Как идёт этап

1. **Решения — днём.** Прочитать файл этапа и заметки понятий его области (сверить с кодом). Вопросы из «Решить до кода»
   и найденные по ходу — пользователю, с вариантами и рекомендацией первой. Ответ — строкой `решения.md` (`Д.<этап>.N`),
   правка заметки понятия — в том же коммите; в файле этапа — «Решено (Д.N)» вместо вопроса.
2. **Работа — ночью**, новой сессией по навыку `night-run` (несколько этапов до срока — `night-until`). Ночной раздел
   («Ночь»: особые правила, ход) — в файле этапа.
3. **Шаг:** сделать → проверить → коммит и `git push` → в файле этапа у пункта — «сделано <дата>, <коммит>», цифры.
4. **Закрытие** — все пункты ниже, по порядку:
   - каждый пункт файла этапа (цель, очередь, «Перенесено», «Аудит») сделан или перенесён в файл другого этапа
     («Перенесено» там) с причиной;
   - проверочный прогон — новая игра за Швейцарию, до конца 1847 (пользователь 12.10: окна «за 10 лет» видны, прогоны
     сравнимы по годам; дальше 1847 не крутить, пока механики не сбалансированы; навык `vic3-sandbox`); пока — рабочие
     прогоны по 5 лет, до конца 1840 (пользователь 12.10): [[Скорость|скорость]] (`v3 log speed`) и профиль — записать
     для R11, условием закрытия не служат (Д.R8б.31), `v3 log diff` против базы CMF + ETF; ошибок по файлам форка — 0;
     проверки этапа — раздел «Закрытие» файла этапа;
   - `ld_smells.py summary` до и после; `v3 lint`, `ld_index.py`, `ld_docs_check.py`, генераторы с `--check`;
   - заметки понятий области — «Что в коде» по факту, `docs/` — по коду;
   - файл этапа → `история/ГГГГ-ММ-ДД этап <этап>.md` (`git mv`) с разделом «Итог» в начале: что сделано (коммиты),
     цифры прогона, смеллы до / после, куда что перенесено; строка в `история/README.md`; в таблице выше — «закрыт
     <дата> — [архив]»; «Состояние» переписать (одно текущее).

**Сквозное, без своего этапа:** правишь файл — снимай в нём дубли (С9), новые числа — сразу именованными (С10),
комментарии-историю (С14). Дорогая строка без этапа: `$VALUE$` в `zz_ef_money_ledger_delta` (0,56 + 0,57 с профиля).
Снимок аудита смеллов со столбцом «что сделано» — [план до разбора по
этапам](история/2026-10-09%20план%20до%20разбора%20по%20этапам.md); пересчёт — `ld_smells.py`.
