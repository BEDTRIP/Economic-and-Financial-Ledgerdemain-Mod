## Цель

- **Денежная власть** — ЦБ, казна или банки: одни счета резерва и выпуска, ИИ (печать, привязка, чеканка), одно окно
  игрока «денежная власть». Без ЦБ — казна при фиате, внешневалютном и обменном (монетный двор — при металлическом),
  банки — при металлическом ([[Свободные банки]]).
- **ЦБ — компания** (государственная / частная: историческая компания-ЦБ, межрыночный банк по концессии, «Национальный
  банк <страны>»; пробы: слот, роспуск ИИ — Р25; область компании в `script_docs` — Р24); роль — переменная,
  `has_central_bank` — флаг; здание ЦБ E&F — в архив; **хранилище металла ЦБ — один раз сюда**, на его «Банки».
- **Банк = компания** (капитал, резервы, доли вкладов и кредита, без поштучных портфелей), агрегаты «частные банкиры» /
  «госкассы»; ёмкость по уровням (размер моста оценить до этапа, что можно — из скрипта); резервы, вклады, ставки, доля
  в кредите = ёмкость × привлекательность ставки, специализация; кредит последней инстанции; кредит другим странам — вид
  требования на бирже (перепродажа банку ближе к должнику); банкротство банка (очередь, раз в месяц; у Б — частичное
  агрегата); портфель банка — словари требований R8б по каждому банку вместо агрегата; арбитражи E&F — в архив.
- **Межрыночные банки и зарубежные отделения** — этап R9а ([[Межрыночный субъект]], Д.R8б.7).
- Правила выпуска денег по стандарту (шаг 3 R3: чеканка, пределы).

**Результат:** банковская система по [[Банки]]. Прежние задачи: Ф3, В7, EF.42, В2.13, Д2.9а, Д2.15, Д2.16.

## Перенесено

- Из R8б (пользователь 10.10) — **панель «Инвестиционный пул — Частный банк»**: средства поровну у всех банков, металл 0
  — показывать счёт каждого банка (доля пула по уровням, свой металл).
- Кнопка E&F «валюта в пул» (`transfert_currency_to_investement_pool_button`, окно ставки ЦБ) — проводкой (перевод
  излишка казны снят, `_archive/ld_tr_surplus_pool/`).
- Капитал банков уходит в минус к 1838 (Британия −0,26…−0,32 млн: проценты по вкладам из капитала при малом кредите;
  Франция −20,7 тыс.; на первом шаге < 0 — США, Россия).
- Частный ЦБ (Д.R8а.9) и денежная власть без ЦБ (Д.R8а.12) — [справка R8а](../история/справка%20—%20решения%20R8а.md);
  план пробы — архив ночи до 8:00 8.10, «Ход ночи» 06:32.
- **Вечное банкротство ЦБ E&F** (`is_extreme_weak_currency`: ценность в золоте по шкале E&F < 0,01 или уже
  `central_bank_bankruptcy`): Австрия — с весны 1836 во всех прогонах; Ганновер — с постройки ЦБ на чужом рынке
  (r1009_130808, `EFC|…|issuer|crisis 2`) при покрытии 150. Перевести проверки на `zz_ef_value_to_parity` и покрытие.
- Дорогая строка: триггер легитимности в `zz_ef_cb_rule_stability` (`ld_cb_rate_values.txt:165`, 0,8 с на 21 тыс.
  вызовов).
