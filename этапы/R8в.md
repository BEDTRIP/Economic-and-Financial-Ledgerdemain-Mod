# R8в. Клиринг и один рынок

**Статус:** после R8б. Ход и закрытие этапа — `план.md`, «Как идёт этап».

**Понятия:** [[Клиринг]], [[Зачёт по группам металла]], [[Один рынок]], [[Торговля с заграницей]],
[[Дивиденды через границу]], [[Валютные союзы]], [[Рычаги на движок]], [[Валюта страны]]. **Решения:** Д.R8в.1–Д.R8в.3,
Д.R8а.3 (`решения.md`). **Код:** `docs/clearing-fx.md`, `docs/currencies.md`, `docs/money-model.md`.

## Цель

Страны в одном рынке — расчёт каждого члена с рынком в своей валюте, зачёт внутри рынка, внешняя торговля рынка по
членам. Клиринг — платёжная система недели: получатель получает требование на плательщика или металл, ненужное продаёт
на бирже; без главы и масштабов палаты; безвалютные — мировая строка (роль В — явный счёт); мировые масштабы той же
недели + строка «рынок-посредник»; дивиденды — калибровка по сейву; рычаги торговли; валютные союзы (латинский,
скандинавский); расчёты таможенного союза; законы валют — в архив.

**Результат:** внешний сектор по [[Клиринг]]. Прежние задачи: Ф8, блок И (союзы, клиринг в золоте), аудит Ч1–Ч4, Ч6.

## Очередь

1. **Страны в одном рынке** (Д.R8в.1) — позиция члена = (доля в производстве рынка − доля в потреблении) × оборот рынка;
   доли — двоичным поиском по триггерам `market_production_share` / `market_consumption_share` (скоуп — рынок,
   `{ target = <страна> goods = <товар> value > x }`; 7 сравнений на долю до 1 %). Проба (r1009_041102,
   `_archive/ld_probe_mshare/`): доли читаются, меньше секунды на 20 проходов по всем странам. Зачёт внутри рынка,
   внешняя торговля рынка (торговые пути хозяина) — по членам. Снимает аудит Ч1 (г) и Ч3 (`zz_ef_members_trade_sum`).
2. **Клиринг — платёжная система недели** — получатель получает требование на плательщика (вклад в его банках) или
   металл; ненужное продаёт на бирже (R8б); запас палаты по 95 валютам (`zz_ef_clr_c_<cur>`) и масштабы палаты — снять;
   чистая позиция каждого участника; участник — денежная власть страны (ЦБ, без ЦБ — банковский агрегат); без главы
   клиринга (Ч2, Ч6); безвалютные — мировой строкой (роль В — явный счёт). **Зачёт по группам металла** (Д.R8в.2,
   [[Зачёт по группам металла]]): внутри группы — по паритетам; остаток — через биржу по мировой цене с комиссией; фиат
   — своя группа по текущим курсам; биметалл — по законному соотношению (`zz_ef_bimet_ratio`), так же биметалл с чисто
   золотой или серебряной страной (против мировой цены). **Спрос получателя на металл** (Д.R8в.3) — по его стандарту:
   металлический — металл по силе валюты плательщика (`zz_ef_clr_metal_share`); обменный от плательщика с разменом
   (`zz_ef_rq_conv`) — без металла, пока его покрытие не ниже `zz_ef_value_floor_cover`, ниже и от валюты без размена —
   как металлический; фиат — что дают. Проверка — прогон: обменные страны получают меньше металла и больше разменных
   валют, металлические — наоборот; мировая сумма металла клиринга сходится.
3. **Остальное по схеме** — мировые масштабы той же недели и строка «рынок-посредник» (Ч4: `zz_ef_wtr_kr/kp`,
   `zz_ef_tr_abr_overlap`), дивиденды (калибровка по сейву или мостом у роли А), рычаги торговли, валютные союзы,
   расчёты таможенного союза (`zz_ef_cu_member`).
4. **Законы валют — в архив** (`_archive/ef_currency_laws/`), когда читателей не осталось (`ld_index.py`): 95 законов и
   группа, законы в истории E&F (35 `activate_law`) → данные (модель уже читает `var:zz_ef_cur`),
   `currency_identifiers_<cur>`.
5. **Остаток R8а:** ввод валюты технологией `introduction_new_currency` и обёртка `zz_ef_cur_intro_*` (новая страна из
   унии получает паритет E&F — Ганновер 3,32 → 18,9), лидер валюты `<cur>_leading_currency_type` и списки
   `08_list_effect`, `introduction_of_<cur>` (С15), `trade_balance_in_gold_fixe`; таблица `zz_ef_fx_gold_<cur>` /
   `global_var:zz_ef_fxvtp_<cur>` → данные эмитента; цепочка `money_value_<cur>` E&F — с окнами и суммами E&F; валютная
   часть `10_new_country_var.txt` (Ч9, 14,4 тыс. строк); проверки закона валюты в E&F (окна 1330, месячный путь 1145).

## Аудит — закрыть или перенести с причиной

`zz_ef_fxvtp_<cur>`; С4 `zz_ef_members_trade_sum`, `leading_currency_type`; С8 законы валют в архив (`on_activate` 95
законов); С11 `zz_ef_std_switch_*`, `zz_ef_cur_intro_*`, `trade_balance_in_gold_fixe`; Ч9, Ч10
`currency_identifiers_<cur>`, С15 `introduction_of_<cur>`, С17 проверки закона в E&F (2475); профиль — клиринг с
лестницами (6,87 с). **Методика сравнения прогонов:** «прочее» мира в прогонах с одним кодом — от −14 до −65 тыс. / нед,
одним прогоном изменения не сравнить — серия или фиксированный сейв.
