# R8в. Клиринг и один рынок

**Статус:** готовится к ночи (10.10): решения Д.R8в.4–9 приняты. Ход и закрытие этапа — `план.md`, «Как идёт этап».

**Понятия:** [[Клиринг]], [[Зачёт по группам металла]], [[Один рынок]], [[Торговля с заграницей]],
[[Дивиденды через границу]], [[Валютные союзы]], [[Рычаги на движок]], [[Валюта страны]]. **Решения:** Д.R8в.1–Д.R8в.18,
Д.R8а.3 (`решения.md`). **Код:** `docs/clearing-fx.md`, `docs/currencies.md`, `docs/money-model.md`.

## Цель

Страны в одном рынке — расчёт каждого члена с рынком в своей валюте, зачёт внутри рынка, внешняя торговля рынка по
членам. Клиринг — платёжная система недели: получатель получает требование на плательщика или металл, ненужное продаёт
на бирже; без главы и масштабов палаты; безвалютные — мировая строка (роль В — явный счёт); мировые масштабы той же
недели + строка «рынок-посредник»; дивиденды — калибровка по сейву; рычаги торговли; валютные союзы (латинский,
скандинавский); расчёты таможенного союза; законы валют — в архив.

**Результат:** внешний сектор по [[Клиринг]]. Прежние задачи: Ф8, блок И (союзы, клиринг в золоте), аудит Ч1–Ч4, Ч6.

## Решено

- **Д.R8в.1** — страны одного рынка: позиция члена по долям рынка (производство − потребление) × оборот; **Д.R8в.8** —
  доли раз в месяц, между расчётами — последнее значение.
- **Д.R8в.2** — зачёт по группам металла.
- **Д.R8в.4** — платежи: сальдо сводятся внутри группы металла, остаток — между группами; каждый получатель получает от
  каждого плательщика своей группы долю, пропорциональную их сальдо, — набором по Д.R8в.11; общей кассы палаты нет.
- **Д.R8в.5** — валютный союз — общая валюта: каждый ЦБ члена выпускает её по общему паритету (одна `var:zz_ef_cur`),
  покрытие — по союзу (металл всех ЦБ / M2 союза), ключевая ставка одна — у лидера; платежи между членами — без клиринга
  и биржи; вступление — статьёй договора (Д.R8в.13); вышедший член — своя валюта по паритету союза.
- **Д.R8в.6** — дивиденды через границу: ВВП во владении иностранцев (мост бюджета) × доходность капитала страны зданий
  (прибыль бизнеса / ВВП); «15 %» снимается.
- **Д.R8в.7** — ввод валюты E&F не трогает страну с валютой и паритетом (закон, паритет, резервы остаются); ввод с
  паритетом — только стране без денежной системы, паритет — от денег, ходивших на её земле; скачок Ганновера (3,32 →
  18,9) — случайный паритет 15–30 скрипта ввода E&F (`introduction_of_<cur>`, вызов из `macro_facilities_bc`).
- **Д.R8в.9** — скорость не условие закрытия (Д.R8б.31).
- **Д.R8в.13** (заменяет Д.R8в.12) — валютный союз — один механизм: статья договора «Монетарная интеграция» между любыми
  двумя странами с хорошими отношениями; договор с главой — членство со всеми членами (треугольника нет); торг — обычным
  договором игры; 3-й уровень «Объединения рынков» — плюс к согласию в блоке и запись дневника «Монетарный союз»;
  Латинский и Скандинавский — исторический толчок, записи E&F — в архив.
- **Д.R8в.15** (заменяет Д.R8в.14) — союз — связные договоры (у каждого члена — с главой на день вступления); глава —
  член с наибольшим престижем (в блоке — лидер блока), смена — как борьба за лидерство в блоке; новый глава — новая
  валюта союза, все пересчитываются; разрыв договора отделяет всех, кто держался через него (двое и больше — свой союз).
- **Д.R8в.16** — Латинский и Скандинавский — записи дневника-цели Франции и Швеции на договорах: с кем союз есть и нет;
  половина списка — престиж; чужой союз или 25 лет — провал; исторические названия союзов.
- **Д.R8в.17** — доступ к союзам — технология у обеих сторон, без дат; пока `central_banking` («принято ночью»),
  окончательно — R11.
- **Д.R8в.18** — запись «Монетарный союз блока» у лидера блока с технологией: что это, роль 3-го уровня «Объединения
  рынков», кто из блока в союзе; половина блока в союзе — престиж; у членов — сводка; принципы ИИ — как в игре.
- **Д.R8в.11** (заменяет Д.R8в.3, Д.R8в.10) — платёж — набор: n % валютой плательщика (у получателя — требование на
  него), n растёт с силой валюты плательщика и доверием к ней (у эталона больше); остаток — по стандарту получателя:
  металлический — металлом из резервов плательщика (не хватает — валютой получателя), обменный и фиат — валютой
  получателя: сначала из резервов плательщика в ней, потом покупка на бирже; не купленное — долг недели. Металл ездит
  только к металлическим стандартам.

## Очередь

1. **Страны в одном рынке** (Д.R8в.1) — позиция члена = (доля в производстве рынка − доля в потреблении) × оборот рынка;
   доли — двоичным поиском по триггерам `market_production_share` / `market_consumption_share` (скоуп — рынок,
   `{ target = <страна> goods = <товар> value > x }`; 7 сравнений на долю до 1 %). Проба (r1009_041102,
   `_archive/ld_probe_mshare/`): доли читаются, меньше секунды на 20 проходов по всем странам. Зачёт внутри рынка,
   внешняя торговля рынка (торговые пути хозяина) — по членам. Снимает аудит Ч1 (г) и Ч3 (`zz_ef_members_trade_sum`).
2. **Клиринг — платёжная система недели** (Д.R8в.4) — по группам металла, доля каждого получателя от каждого плательщика
   группы — пропорционально сальдо; **платёж — набор** (Д.R8в.11): n % валютой плательщика (требование получателя на
   него; n — по силе валюты плательщика, `zz_ef_clr_metal_share` в обратную сторону), остаток — металлическому стандарту
   металлом из резервов плательщика, обменному и фиату — валютой получателя: резервы плательщика в ней
   (`zz_ef_rq_cb_m`), потом заявка на покупку в стакан его биржи (по верхнему шагу); не купленное — долг недели;
   ненужное получатель продаёт на бирже (R8б); запас палаты по 95 валютам (`zz_ef_clr_c_<cur>`) и масштабы палаты —
   снять; чистая позиция каждого участника; участник — денежная власть страны (ЦБ, без ЦБ — банковский агрегат); без
   главы клиринга (Ч2, Ч6); безвалютные — мировой строкой (роль В — явный счёт). **Зачёт по группам металла** (Д.R8в.2,
   [[Зачёт по группам металла]]): внутри группы — по паритетам; остаток — через биржу по мировой цене с комиссией; фиат
   — своя группа по текущим курсам; биметалл — по законному соотношению (`zz_ef_bimet_ratio`), так же биметалл с чисто
   золотой или серебряной страной (против мировой цены). Проверка — прогон: обменные страны получают меньше металла и
   больше разменных валют, металлические — наоборот; мировая сумма металла клиринга сходится.
3. **Остальное по схеме** — мировые масштабы той же недели и строка «рынок-посредник» (Ч4: `zz_ef_wtr_kr/kp`,
   `zz_ef_tr_abr_overlap`), дивиденды (Д.R8в.6: ВВП во владении иностранцев с моста × прибыль бизнеса / ВВП страны
   зданий), рычаги торговли, расчёты таможенного союза (`zz_ef_cu_member`).
4. **Валютные союзы** (Д.R8в.5, Д.R8в.13, Д.R8в.15) — (а) механика союза: союз — глава и члены; валюта союза — валюта
   главы; члены на `var:zz_ef_cur` союза, стандарте и паритете союза; деньги, счета и требования члена пересчитываются
   по отношению паритетов — стоимость в золоте не меняется (лог `EFM`); покрытие — металл всех ЦБ / M2 союза, ставка —
   главы; платежи между членами — внутри союза, без клиринга и биржи; выход — своя валюта по паритету союза; (а2) глава
   и связи (Д.R8в.15): у члена — переменная, с кем его договор (глава на день вступления); глава — член с наибольшим
   престижем, в союзе блока — лидер блока; смена — претендент обгоняет главу на порог борьбы за лидерство (`NPowerBlocs`
   `POWER_STRUGGLE_PRESTIGE_THRESHOLD_START` / `_FAIL`, `POWER_STRUGGLE_DURATION_SUCCESS_MONTHS` — прочитать в
   `defines`) дольше её срока; при смене — валюта, стандарт и паритет нового главы, пересчёт всех членов (`EFM`); разрыв
   договора — все, кто держался через разорвавшего, отделяются: двое и больше — свой союз (глава по престижу, его
   валюта), один — своя валюта по паритету союза; выход из блока у союза блока — разрыв договоров этой страны, члены
   блока за ней перевешиваются на главу; (б) статья договора `ld_monetary_integration`
   (`common/treaty_articles/ld_monetary_integration.txt`, по образцу `09_join_power_bloc.txt`): `kind = directed`,
   `can_ratify` — у обеих технология союзов (`central_banking`, Д.R8в.17), одна сторона глава союза или обе вне союзов,
   другая вне союза, отношения не ниже «сердечных» («принято ночью»); `on_entry_into_force` — вступление в союз главы
   или основание союза; `on_break` / `on_withdrawal` — выход; `article_ai_usage = { offer request }`; ИИ:
   `inherent_accept_score` слагаемыми с подписями (база, отношения, доля торговли с главой, группа металла, сила своей
   валюты, великая держава; в блоке с `principle_market_unification_3` — сильный плюс) — числа «принято ночью»,
   `evaluation_chance` по весу; (в) союз блока — выход из блока: без таможенного союза и валюты; (г) запись дневника
   «Монетарный союз блока» (`ld_monetary_union_je`, Д.R8в.18) — у лидера блока с технологией союзов, у игрока и ИИ: что
   такое союз, 3-й уровень «Объединения рынков» облегчает согласие; по членам блока — кто в союзе, кто нет, выпуск и
   запасы валюты союза, покрытие, доля в торговле; выполнена — половина членов блока в союзе лидера, награда — престиж;
   у членов блока с союзом — та же сводка без цели; веса принципов ИИ не трогать; (д) Латинский и Скандинавский
   (Д.R8в.16) — записи дневника-цели `ld_latin_union_je` (Франция: Бельгия, Швейцария, итальянские государства или
   Италия, Греция) и `ld_scandinavian_union_je` (Швеция: Дания, Норвегия) у игрока и ИИ: список — кто в союзе, кто нет;
   выполнена — не меньше половины списка в союзе, награда — престиж; провал — страна в чужом союзе или 25 лет с
   открытия; открываются с технологией союзов (Д.R8в.17); ИИ — большой `evaluation_chance` и плюс к согласию для стран
   списка; союз с главой Францией / Швецией и членом из списка называется Латинским / Скандинавским;
   `latin_monetary_union_je_1`, `scandinavian_monetary_union_je_1`, статьи договоров E&F `latin_monetary_union_treaty`,
   `scandinavian_monetary_union_treaty` (`common/treaty_articles/16_…`, `17_…`) и события переговоров
   `00_ef_economic_event` — в `_archive/` по его правилам; локализация — русская и английская, `ld_loc_langs.py`.
   Проверка — прогон (новая игра; союз консолью или сейвом): статья видна в договоре, ИИ отвечает с подписями слагаемых,
   третья страна вступает договором с главой, запись Латинского союза у Франции считает список, смена главы переводит
   союз на его валюту, разрыв отделяет ветку, союз в логе (`EFM`), паритеты членов равны, покрытие общее.
5. **Законы валют — в архив** (`_archive/ef_currency_laws/`), когда читателей не осталось (`ld_index.py`): 95 законов и
   группа, законы в истории E&F (35 `activate_law`) → данные (модель уже читает `var:zz_ef_cur`),
   `currency_identifiers_<cur>`.
6. **Остаток R8а:** ввод валюты технологией `introduction_new_currency` и обёртка `zz_ef_cur_intro_*` (Д.R8в.7: страна с
   валютой и паритетом их сохраняет — Ганновер при выходе из унии остаётся на 3,32; ввод с паритетом — только без
   денежной системы, паритет — прежнего эмитента × его курс), лидер валюты `<cur>_leading_currency_type` и списки
   `08_list_effect`, `introduction_of_<cur>` (С15), `trade_balance_in_gold_fixe`; таблица `zz_ef_fx_gold_<cur>` /
   `global_var:zz_ef_fxvtp_<cur>` → данные эмитента; цепочка `money_value_<cur>` E&F — с окнами и суммами E&F; валютная
   часть `10_new_country_var.txt` (Ч9, 14,4 тыс. строк); проверки закона валюты в E&F (окна 1330, месячный путь 1145).
