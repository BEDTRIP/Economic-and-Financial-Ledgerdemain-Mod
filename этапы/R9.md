5. **Капитал банков сверх норматива — владельцам** (Д.R9.3): раз в месяц у субъекта капитал сверх 10 % доходных активов
   (принято ночью) — компании-банку на счёт (`zz_ef_co_acc`, вклады компаний), «частным банкирам» — во вклады населения,
   «госбанкам» — в казну (проводка пул → казна); книга сходится, «прочее» не двигается. Проверка: капитал банков /
   доходные активы к ~10 %, «прочее» < 1 % M2.
6. **Ставка банка по кредиту** (Д.R9.1): у субъекта ставка кредита = `zz_ef_cc_rate` + надбавка от доли капитала (как
   `zz_ef_bk_prem_v`); новый деловой кредит — по свободному лимиту (шаг 7) × привлекательности (ниже ставка — больше);
   проценты страны — сумма по субъектам. Проверка: `EFJ|bank_sum` diff 0, «прочее», ставки субъектов в логе.
7. **Лимит банка** (Д.R9.2): кредиты субъекта ≤ капитал × плечо; плечо = база × (ставка-ориентир / ключевая), в пределах

   — всё равно кредит, отметка в логе. Проверка: кредиты / капитал ≤ плеча, доля частной стройки следует за лимитом.
8. **Потребкредит без ЦБ** (Д.R9.6): `zz_ef_consumer_credit_step` — у всех стран с пулом; ставка без ЦБ — ставка
   правительства + 3 п. п.; покрытие (`zz_ef_cb_cover_credit_mult`) без ЦБ — 1. Проверка: страны без ЦБ — `cc_debt` > 0,
