## Цель

Компания — субъект модели со своим счётом (вклад в банках, Д.R6.7): кредит банков, дивиденды, выход на биржу (IPO);
частный сектор вне компаний — собиратель; листинг на бирже страны (места — по уровням финцентра); акции — вид требования
на бирже, цена — годовые дивиденды / (ставка правительства + 4 п. п.) (Д2.10); методы акций — по условиям игры; продажа
зданий пересозданием (таблица групп методов — генератор); банкротство компании; капитализация одной суммой;
`bankrupt_company` E&F — в архив.

**Результат:** субъект «компания» по [[Компания]]. Прежние задачи: Ф6, EF.17, EF.20, EF.22, EF.35, СТР.5.

0. **Проверка влитого** — выкуп уровней продавцу (Д.R6.1), архив `bankrupt_company`, сбережения = банкноты + вклады

   сбережения − банкноты − вклады ≈ 0 (`EFW|acc`: `savings`, `cash`, `deposits`). **Сделано 14.10** (прогон
   r1014_071539, код `61a2260`, до 1.3.1841): выкуп уровней `lvl_pool` — 0 все месяцы; «прочее» мира 1,03 млн = 0,3 % M2
   (база r1014_045404 к 1841 — того же порядка); сбережения − банкноты − вклады мира −0,08…+0,01 млн при 160–240 млн;
   ошибок по файлам форка 0 (3 — `company_charter_types` игры); EFQ 0, суммы банков = счета (diff 0). M0 / ВВП 0,40–0,47,
   M1 0,58–0,71, M2 0,73–0,78 — к ориентиру Д.R7.3 (R7). Скорость 12,8 → 16,6 с на игровой месяц.

   `docs/exchange-companies.md` и `../vic3_mods/Правила работы с модами Victoria 3.md` (раздел движка).
2. **Счёт компании** (Д.R6.7): переменная на компании (или список на стране — по пробе); взносы в пул

   населения; доля компаний в возврате сгоревшего (`zz_ef_t_lb_c`) — по счетам; вклады компаний `zz_ef_comp_dep` = сумма

3. **Кредит компаний и стройка** (Д.R6.9, Д.R6.13): `zz_ef_bc_debt` — по компаниям по доле уровней (новый кредит,
