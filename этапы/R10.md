# R10. Интерфейс

**Статус:** после R9. Ход и закрытие этапа — `план.md`, «Как идёт этап».

**Понятия:** [[Витрина]], [[Мост GUI]], [[Сверка по запасам]]; все понятия — подсказки в игру (раздел «Подсказка»
заметок `понятия/`). **Код:** `docs/interface.md`.

## Цель

Вкладки «Экономика» и «Финансы / ЦБ» на субъектах (балансы ЦБ, банков, населения, компаний, казны, фондов); **окно
биржи** — котировки, заявки игрока, управление биржей (комиссия, запреты); нужные окна E&F — пересобрать, остальные — в
архив; **понятия и подсказки** — тексты «Подсказка» из `понятия/` в локализацию как есть (абзац — одна строка, между
абзацами — `\n\n`, вики-ссылки на заметки → ссылки на понятия игры и мода); **символ валюты в тексте** — съезжает ниже
строки, у 2–3-буквенных слишком длинный.

**Результат:** игрок видит систему. Прежние задачи: блок З — UI.1–UI.15, В5.7, В10.

## Перенесено

- Из R8в (12.10) — **список валют окна E&F** (`stored_currency`, `update_currency_stored_liste`,
  `00_ef_economic_global_variable.txt`): 95 флагов `<cur>_02` — «set but never used» (элементы списка, а не сравнения);
  уходят с окном.
- Из R8в (11.10) — **сводка валютного союза у членов блока** без цели (запись «Валютный союз блока» есть только у лидера
  блока): у членов — та же сводка (кто в союзе, покрытие, выпуск), без награды.
- Из R8в (шаг 6, 11.10) — **подписи валюты-эталона E&F** (`global_monetary_reference_name`, `_texture`,
  `_currency_good`, `_currency_ISO_4217` и ключи `<cur>_ISO_4217`, `<cur>_good`, `<cur>_texture`): окну нужна
  страна-эталон как скоуп — тогда её `currency_code` / `currency_symbol` (Д.R8в.20); 1245 ключей `<cur>_0N_*` окон E&F,
  которых нет, — в архив.
- Из R8б (предложено 10.10, не решено) — **суммы в валюте страны** в панелях мода: сумма движка × единиц своей валюты на
  единицу по паритету; цены движка не меняются (у игры нет множителя цены рынка, торговля идёт по разнице цен в общей
  единице).
- Из R8б (пользователь 10.10) — **прогноз денежной системы** (Бюджет → Финансы, «Мировые цены на металлы и прогноз»,
  колонки MVT / CBMR / MSPM): считается только для текущего стандарта, у остальных — нули; считать для всех стандартов.
- **Одно «прочее»:** карточки счетов и лог `EFO` показывают потоковые остатки хотфикса (`zz_ef_leak_week`, `pool_other`,
  `tr_other`), а не запас сверки — свести к разбивке запасного «прочего» по статьям (по странам за 3 года: Франция −1,08
  млн, Цин −0,78, Британия −0,74, Россия −0,62).
- **Витрина:** большая часть имён (416 из 586, `ld_vitrine.py`) считается при перерисовке → в переменные шага.
